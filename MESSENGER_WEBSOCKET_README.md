# Мессенджер - Документация по WebSocket

## Команда запуска WebSocket сервера

```bash
php ws_server/server.php
```

Или для запуска в фоновом режиме:

```bash
php ws_server/server.php start
```

Для остановки сервера:

```bash
php ws_server/server.php stop
```

Для перезапуска:

```bash
php ws_server/server.php restart
```

## Архитектура подключения

### Глобальное WebSocket подключение

WebSocket соединение устанавливается **на старте приложения** при загрузке любой страницы. Это реализовано в файле `/app/views/core/common.js`.

**Преимущества:**
- Мгновенное получение уведомлений о новых сообщениях на любой странице
- Счетчик непрочитанных сообщений обновляется в реальном времени
- Браузерные push-уведомления работают глобально
- Автоматическое переподключение при разрыве соединения

## Подключение к серверу

Сервер слушает порт **27800**:

```javascript
const conn = new WebSocket(`ws://localhost:27800?user_uid=${user_id}`);
```

## Формат сообщений

### Отправка команды на сервер:
```json
{
    "action": "get_dialogs",
    "data": {
        "user_id": 123
    }
}
```

### Получение ответа от сервера:
```json
{
    "action": "get_dialogs",
    "data": {
        // данные диалогов
    }
}
```

## Доступные действия (actions)

| Действие | Описание |
|----------|----------|
| `get_dialogs` | Получить список диалогов пользователя |
| `get_messages` | Получить сообщения конкретного диалога |
| `send_message` | Отправить сообщение |
| `edit_message` | Редактировать сообщение |
| `delete_message` | Удалить сообщение |
| `send_chat_action` | Отправить статус (например, "печатает") |
| `get_unread_count` | Получить количество непрочитанных сообщений |
| `PingSocket:index` | Ping для поддержания соединения |

## Уведомления

Система поддерживает:
1. **Браузерные Push-уведомления** - требуют разрешения пользователя
2. **Обновление счетчика** в заголовке страницы
3. **Звуковые уведомления** (опционально, требует добавления аудиофайла)

## Проверка работы

1. Запустите WebSocket сервер:
   ```bash
   php ws_server/server.php start
   ```

2. Откройте приложение в браузере

3. Проверьте консоль разработчика (F12):
   - Должно быть сообщение `WebSocket connected`
   - При получении сообщения должно приходить уведомление

4. Проверьте вкладку Network -> WS:
   - Должно быть активное WebSocket соединение на порт 27800

## Возможные проблемы

### WebSocket не подключается
- Проверьте, запущен ли сервер командой `ps aux | grep server.php`
- Проверьте, свободен ли порт 27800: `netstat -tlnp | grep 27800`
- Убедитесь, что брандмауэр не блокирует порт

### Сообщения не приходят
- Проверьте логи сервера в `.logs/`
- Убедитесь, что пользователь авторизован
- Проверьте корректность `user_id` в URL подключения

### Ошибки базы данных
- Убедитесь, что таблица `dialog_users` существует
- Проверьте права доступа к БД
