# My Local Server System
## Description
PHP суперприложение для работы с: 
* персональными заметками на корпоративном предприятии;
* другие приколы планируются
## Requirement
-> PHP7.1
-> SQLite3 
## Планы на версию 1.4:
* Переписать класс Models. Это позволит работать с БД.
* Перенести информацию о файлах заметок в БД. Информация, которая там будет храниться:
* * Название заметки
* * Автор заметки
* * Ссылка на заметку
* * Дата создания
* * Дата редактирования
* Профили пользователей. Теперь можно будет ввести понятие персональных страниц со списком собственных заметок. Информация о пользователе: 
* * Имя пользователя
* * Персональный ключ
* * Уровень доступа (Админ, пользователь)
* Доработать пагинацию в главной ленте заметок.
* Появление профилей пользователей позволит модифицировать авторизацию.
* Появление профилей пользователей позволит разделить возможность редактирования раметок.
