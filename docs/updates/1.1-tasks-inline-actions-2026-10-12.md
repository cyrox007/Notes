# Tasks 1.1: действия внутри страницы без полной перезагрузки

Дата: 12 октября 2026 года.

## Что изменено

В списке задач четыре частых пользовательских действия переведены на локальное обновление интерфейса:

- добавление подзадачи;
- удаление подзадачи;
- назначение категории задаче;
- снятие категории с задачи.

После успешного запроса браузер больше не выполняет полную перезагрузку страницы. Клиент повторно получает текущую страницу, извлекает из серверной разметки только нужный фрагмент карточки и заменяет его в уже открытом интерфейсе.

Для подзадач обновляется только блок `.task-subtasks`, для категорий — только `.task-meta`. Благодаря этому отображение остаётся единым с серверным PHP-шаблоном и не появляется отдельная клиентская копия правил оформления.

## Поведение при ошибке

На время запроса управляющий элемент блокируется. Если операция или локальное обновление не удалось, пользователь получает сообщение об ошибке, а элемент снова становится доступным.

Переключатели новых подзадач обслуживаются делегированным обработчиком, поэтому продолжают работать после замены блока без повторной инициализации всей страницы.

## Что не менялось

Визуальный стиль Tasks не изменялся. Работа касается только поведения существующих элементов и уменьшения количества полных перезагрузок страницы.

Обычная навигация между самостоятельными страницами остаётся без изменений.
