# 1.2 — эксплуатационный runtime PHP 8.3

Дата: 17 октября 2026.

Второй технический этап линии 1.2 проводит ранее объявленный минимум PHP 8.3 через реальные точки запуска системы.

Что изменено:

- web-установщик требует PHP 8.3+;
- `bin/healthcheck.php` проверяет минимум линии 1.2;
- общий `CliRuntime` останавливает cron, worker и служебные команды при запуске на PHP ниже 8.3;
- автономный внешний обновлятор имеет собственную такую же защиту и не зависит от live-tree;
- `UpdatePhpCli` проверяет не только наличие `UPDATE_PHP_BINARY`, но и фактическую версию выбранного CLI;
- если подходящий CLI отсутствует, process-режим обновления не объявляется доступным и остаётся совместимый web-контур;
- подписанный staged-пакет по-прежнему проверяет `requires_php` до резервного копирования, переключения кода и миграций;
- CI проверяет Linux и Windows на PHP 8.3;
- отдельный интеграционный контракт подтверждает сохранение реального кода завершения дочернего PHP-процесса, что использует исправленную семантику `proc_get_status()` PHP 8.3.

Линия 1.1 не меняется: её системный минимум остаётся PHP 8.2. Переход на PHP 8.3 относится только к 1.2.

Следующий платформенный этап после завершения этой задачи — общий контракт целостности изменяемых данных: версии сущностей, явные конфликты конкурентной записи и идемпотентные команды.
