# Повторные напоминания по командным задачам

Фоновая команда `php bin/tasks_board_overdue_reminders.php --json` публикует события для незавершённых просроченных задач, назначенных конкретному исполнителю. Для внешней доставки отдельно запускается `php bin/notifications_worker.php --json`.

Команду запускают каждые 15 минут. Публикация допускается в период с 09:00 до 09:59 по часовому поясу пользователя. Пользователь должен включить утренние уведомления в Tasks. Канал доставки определяется настройками единой платформы Notifications.

Проверяется принадлежность назначения, активность пользователя, доступ к доске (владелец, участник либо открытая для активных пользователей доска), а также состояние самой задачи и доски. При каждом новом проходе проверяется актуальное состояние данных. Повтор в тот же день защищён уникальным ключом события, содержащим пользователя, задачу и местную дату.

В уведомление не попадает название или содержимое командной задачи. Открытие доски требует обычной авторизации и проверки доступа.

На этапе испытаний автоматическая установка расписания не выполняется. Требуются успешные интеграционные прогоны на MySQL и MariaDB, проверка поведения при конкурирующем отзыве доступа и завершении задач, затем утверждение изменений перед слиянием.
