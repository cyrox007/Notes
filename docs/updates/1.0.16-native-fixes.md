## Incident and regression

User recording `2026-10-10 10-31-19.mp4` demonstrates task moves between columns with a lingering translucent card and unstyled category/subtask controls. A dragged node is reparented during drop, so cleanup must not depend on a later dragend. The global capturing change listener also intercepted the native Tasks persistence handler, bypassing its rollback/counter coordination.

The board now clears drag classes on drop, prevents a second move while saving, and lets the native Tasks handler own its request and error rollback. The drop hint is inserted only when entering a different column, ignores pointer hit testing, and survives child dragleave events without relatedTarget. Active drop targets no longer move their own hit bounds. This also applies to shared boards. Small buttons and controls receive complete module styles, independent of which container currently holds the card.
