# Tasks 1.2 — личные представления по дням

Дата: 19 октября 2026 года.

## Выполненный этап утверждённого плана

Начат второй внутренний этап [развития Tasks](../plans/tasks-evolution.md):
личная рабочая очередь без изменения существующего визуального стиля.

- Основной заголовок — «Мои задачи», список ограничен владельцем на сервере.
- Быстрые представления без раскрытия панели сортировки:
  «Мои задачи», «Сегодня», «Завтра», «Просрочено».
- Для дневных представлений завершённые и отменённые задачи исключены;
  просроченные определяются по фактическому сроку, а не только по дате.
- Рабочие списки по умолчанию показывают ближайший срок первым,
  пользовательская сортировка остаётся доступной.
- Постраничная загрузка, поиск, архив, категории и прежние
  фильтры статусов сохранены.
- Добавлены числовые показатели сегодня, завтра, просрочено;
  значимость состояния не передаётся одним лишь цветом.
- Даты рассчитываются `DateTimeImmutable` с переходом через календарные
  дни. Контракт проверяет смену месяца/года и переходы летнего времени.

## Совместимость и границы

Существующие `tasks.due_date` — значения `DATETIME` без явного
смещения времени. Для этого этапа используется календарная зона PHP
установки, как и в действующем механизме создания задач. **Автоматически
считать её индивидуальным часовым поясом пользователя нельзя.**

Перевод сроков в персональные зоны требует отдельно определить
хранение зоны пользователя, семантику старых `DATETIME`,
отображение и миграцию без сдвига исторических сроков.
Такая поддержка остаётся задачей 1.2 и не объявляется сделанной здесь.

Ручной порядок очереди, командные назначения, ежедневные сводки и
действия из уведомлений — следующие этапы того же утверждённого цикла.

## Проверка

`php tests/integration/tasks_personal_queue_12_contract.php`

Проверяются границы суток (включительно слева, исключительно справа),
отсутствие чужих, архивных и удалённых задач, завершённые статусы,
просрок, обычный недельный фильтр, смена суток и года, DST,
доступность новых представлений в шаблоне.

Контракт подключён к модульному CI на PHP 8.3.
