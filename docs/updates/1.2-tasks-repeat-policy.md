# Настраиваемая частота повторных напоминаний Tasks 1.2

## Настройка пользователем

Откройте «Мои задачи» → «Моя рабочая очередь». Рядом с личным часовым поясом и согласием на утреннюю сводку появился отдельный выбор повторных уведомлений:

- «Не повторять»;
- «Каждый день»;
- «Каждые 3 дня»;
- «Каждые 7 дней».

Настройка общая для личных и назначенных командных задач. Утреннюю сводку можно выключить, оставив повторы, или наоборот. Напоминание отправляется в период 09:00–09:59 по местному времени пользователя только при наличии незавершённой просроченной задачи и действующего доступа к ней.

Первый повтор приходит **на следующий календарный день после установленного срока**, затем с указанным интервалом: каждые три дня означают 1-й, 4-й, 7-й дни просрочки. Задачи без срока, завершённые, архивированные, отменённые или недоступные исполнителю исключаются. Смена часового пояса влияет на следующий местный календарный день; защита от дублей использует местную дату в ключе события.

## Совместимость

Миграция `20261022_tasks_repeat_interval.sql` добавляет nullable-поле `repeat_interval_days` в таблицу `task_morning_digest_settings`. Значение `NULL` означает **прежнее поведение**: у существующих пользователей повторы ежедневно, если была включена утренняя сводка, иначе повторы не отправляются. При первом сохранении пользовательского выбора фиксируется явное значение `0`, `1`, `3` или `7`.

Это позволяет обновить систему, не включая новые уведомления без согласия. Выбор частоты не меняет пользовательские подписки на внешние каналы; для почты или Push дополнительно нужны действующие разрешения категории `tasks.reminders`.

## Проверки

Проверяются четыре интервала, переход через летнее/зимнее время, повторобезопасность, контроль доступа к общей доске, отключение повторов и независимая работа сводки. Тесты запускаются на MySQL 8.4 и MariaDB 11.4, а миграция входит в общий контракт обновления.

**Получение сообщения в настоящем почтовом ящике или на устройстве требует отдельной приёмки установленной системы.** Сквозные автоматические испытания используют безопасный тестовый транспорт и не отправляют письма сторонним людям.
