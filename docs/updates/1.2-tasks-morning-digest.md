# Утренние сводки Tasks — первый этап

Фоновая команда `bin/tasks_morning_digest.php` публикует сводку через единый центр уведомлений. Она **не отправляет** почту или Push самостоятельно: внешнюю доставку выполняет существующий `bin/notifications_worker.php`.

Сводка создаётся в 08:00–08:59 **локального времени пользователя** только для активных пользователей, указавших личный часовой пояс в очереди Tasks и явно включивших флажок «Получать утреннюю сводку», и только при наличии незавершённых задач до конца следующего дня. Публикация защищена ключом `tasks:morning:USER_ID:YYYY-MM-DD`; повторные запуски не должны размножать записи. Исторические даты `DATETIME` не переинтерпретируются как UTC.

Пример запуска планировщиком каждые 15 минут:

```sh
php bin/tasks_morning_digest.php --json
php bin/notifications_worker.php --json
```

Ограничение команды — не более 100 подходящих пользователей за запуск (допустимо 1–500). Для большой установки оператор может продолжить обработку, указав `--after-user=ID`, где ID — последний обработанный пользователь; повторные проходы безопасны. По умолчанию рассылка выключена. Согласие включается и отключается на странице Tasks вместе с сохранением часового пояса.

**Ограничения этапа:** пока нет сохранённого курсора для автоматического обхода больших установок, повторных напоминаний о конкретных задачах и интеграционного испытания фоновой команды на реальной БД. Без этих проверок нельзя считать весь цикл уведомлений завершённым.
