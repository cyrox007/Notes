# Управление планировщиком напоминаний Notes 1.2

## Что видит администратор

Откройте **Администрирование → Каналы уведомлений → Планировщик напоминаний Tasks**. Карточка показывает фактический последний запуск, его состояние, количество сводок и личных/командных напоминаний, а также итоги доставки. Статус «Работает» означает только наличие свежего завершённого прохода. Он не доказывает, что сообщение получено адресатом.

Состояния: «Не запускался» — в журнале нет проходов; «Выполняется» — проход ещё идёт; «Возможное прерывание» — последний проход не завершился более 45 минут назад; «Нет свежих запусков» — успешная запись старше 45 минут; «Ошибка обработки» — последний проход завершился с ошибкой; «Недоступен» — ошибка чтения базы или не применена миграция.

Настройки остальных каналов продолжают работать, даже когда Tasks или журнал недоступны. Чтение карточки не создаёт уведомления и не запускает обработчик. Маршрут уже защищён правом `admin.settings.manage`.

## Linux — установить задание

Запускайте команды **от того пользователя ОС**, которому разрешён запуск Notes. Используйте PHP 8.3 или новее и примените миграции версии 1.2 перед включением расписания.

```sh
bash tools/scheduler/tasks-reminders-linux.sh status
bash tools/scheduler/tasks-reminders-linux.sh install
bash tools/scheduler/tasks-reminders-linux.sh status
```

Если требуется конкретный исполняемый PHP, задайте `NOTES_PHP_BIN=/полный/путь/к/php`. Установщик настраивает один запуск каждые 15 минут в пользовательском cron. Повторный `install` обновляет строку, а не создаёт дубликат. Ошибки выводятся в системный журнал под меткой `notes-tasks-reminders`; для просмотра можно использовать `journalctl -t notes-tasks-reminders` (если доступно).

Чтобы отключить расписание:

```sh
bash tools/scheduler/tasks-reminders-linux.sh remove
```

## Windows / OSPanel — установить задание

Откройте PowerShell с правами на создание задания текущего пользователя. **OSPanel 5.2.2 сам по себе не гарантирует PHP 8.3** — проверьте расположение подходящего PHP.

```powershell
.\tools\scheduler\tasks-reminders-windows.ps1 -Mode Status
.\tools\scheduler\tasks-reminders-windows.ps1 -Mode Install -PhpPath "C:\ПУТЬ\К\PHP83\php.exe"
.\tools\scheduler\tasks-reminders-windows.ps1 -Mode Status
```

Сценарий создаёт задание Windows от текущего пользователя с интервалом 15 минут и рабочим каталогом приложения. Через 10 лет расписание потребуется обновить командой `Install`. При ошибке регистрации проверьте разрешения планировщика Windows. Для отключения:

```powershell
.\tools\scheduler\tasks-reminders-windows.ps1 -Mode Remove
```

## Проверка после установки

Проверяйте карточку в админке после фактического запуска системного задания. Диагностика доступна и через команду `php bin/tasks_reminder_cycle.php --diagnose --json`. Включать отдельные старые задания `tasks_morning_digest.php`, `tasks_overdue_reminders.php` и `tasks_board_overdue_reminders.php` одновременно не следует: они обходят блокировку единого цикла.

**Установка расписания на сервере не происходит при слиянии или обновлении Notes.** Администратор сервера выполняет `install` отдельно. Если задание создано под другим пользователем ОС, команда `status` текущего пользователя не найдёт его; карточка показывает только фактически выполненные проходы, независимо от владельца системного задания.
