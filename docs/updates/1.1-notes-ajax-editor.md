# Notes 1.1 — действия редактора без полной перезагрузки

## Что изменено

В редакторе Notes типовые действия внутри уже открытой страницы выполняются асинхронно и больше не требуют полной перезагрузки редактора:

- сохранение названия и текста заметки;
- загрузка обычного вложения;
- сохранение голосовой заметки;
- создание публичной ссылки;
- отключение публичной ссылки;
- удаление вложения после локального обновления списка.

При сохранении текста сервер по-прежнему выполняет проверку прав, нормализацию названия, ограничение размера и шифрование содержимого. Для AJAX-запроса тот же маршрут возвращает структурированный JSON с подтверждённым названием и временем изменения, а обычная HTML-форма без JavaScript сохраняет прежний переход в список заметок.

Локальный черновик удаляется только после подтверждённого ответа сервера. Если сохранение не удалось, текущий текст остаётся в редакторе и локальный черновик сохраняется для восстановления. Если пользователь продолжил редактирование уже после начала AJAX-запроса, ответ сервера подтверждает только отправленную версию: более новые правки остаются помеченными как несохранённые и продолжают храниться в локальном черновике до следующего сохранения.

Для вложений, голосовых заметок и публичных ссылок клиент повторно получает текущую страницу с сервера и заменяет только тот блок, который изменился. За счёт этого сервер остаётся источником истины, а несохранённый текст в редакторе не теряется.

## Что не изменено

- визуальный стиль и CSS не менялись;
- навигация между отдельными страницами осталась обычной;
- серверная проверка прав, ограничений файлов и публичных ссылок сохранена;
- шифрование текста заметки выполняется тем же серверным механизмом;
- резервный обычный POST для сохранения текста сохранён.

## Проверка

Браузерный жизненный цикл Notes проверяет, что сохранение названия и текста возвращает JSON, не меняет URL и не демонтирует редактор. После этого сценарий специально перезагружает страницу и проверяет, что название и расшифрованный текст действительно читаются из серверного хранилища.

Для остальных AJAX-действий используется DOM-маркер: он должен сохраняться после асинхронного действия, что подтверждает отсутствие полной перезагрузки редактора. Отдельный сценарий проверяет сохранение голосовой заметки тем же AJAX-путём и её последующее воспроизведение из приватного хранилища.
