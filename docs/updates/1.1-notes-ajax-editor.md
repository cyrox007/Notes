# Notes 1.1 — действия редактора без полной перезагрузки

## Что изменено

В редакторе Notes типовые действия внутри уже открытой страницы выполняются асинхронно и больше не требуют полной перезагрузки редактора:

- загрузка обычного вложения;
- сохранение голосовой заметки;
- создание публичной ссылки;
- отключение публичной ссылки;
- удаление вложения после локального обновления списка.

После успешного запроса клиент повторно получает текущую страницу с сервера и заменяет только тот блок, который изменился: список файлов, список голосовых заметок или блок публичной ссылки. За счёт этого сервер остаётся источником истины, а несохранённый текст в редакторе не теряется.

## Что не изменено

- визуальный стиль и CSS не менялись;
- навигация между отдельными страницами осталась обычной;
- серверная проверка прав, ограничений файлов и публичных ссылок сохранена;
- существующие JSON-контракты загрузки, публикации и удаления не менялись.

## Проверка

Браузерные сценарии Notes дополнены проверкой DOM-маркера. Маркер должен сохраняться после асинхронного действия, что подтверждает отсутствие полной перезагрузки редактора. Отдельный сценарий проверяет сохранение голосовой заметки тем же AJAX-путём и её последующее воспроизведение из приватного хранилища.
