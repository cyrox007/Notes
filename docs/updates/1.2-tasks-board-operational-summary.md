# Краткая управленческая сводка Tasks 1.2

На странице «Общие доски задач» выберите доступную доску. Если вы владелец либо назначенный руководитель этой доски, под её обычной сводкой появится раздел «Состояние задач команды».

Показатели вычисляются отдельным запросом к базе для выбранной доски, независимо от количества видимых карточек:

- **Не завершены:** не удалённые и не архивированные задачи без конечного статуса.
- **Просрочены:** не завершённые задачи со сроком ранее текущего времени UTC.
- **Без изменений 7 дней:** действующие задачи в состоянии «Запланировано», «Изучение», «В работе», «Проверка», не обновлявшиеся семь дней.
- **Без исполнителя:** не завершённые задачи, у которых отсутствует назначенный исполнитель.
- **Завершены за 7 дней:** задачи, дата фактического завершения которых входит в прошедшие семь суток.

Показатели могут пересекаться: одна задача одновременно может быть просроченной, зависшей и без исполнителя. Нет скрытого рейтинга сотрудников или автоматической оценки их эффективности.

## Доступ и безопасность

Проверка прав выполняется **на сервере** по идентификатору доски. Читать сводку вправе только владелец либо руководитель с ролью `manager`, если его аккаунт активен, а доска не архивирована. Обычные участники, наблюдатели и пользователи без доступа не получают данные сводки. Используется отдельная агрегированная выборка без заголовков задач, содержимого и личных данных.

Новые таблицы и миграции не требуются. Для достоверности даты завершения необходимо использовать штатные команды изменения состояния задачи.

## Испытания

GitHub Actions проверяет расчёт итогов, отсутствие чужих задач, исключение архивированных и удалённых записей, отзыв прав, неактивный аккаунт и закрытую доску на MySQL 8.4 и MariaDB 11.4. Перед слиянием необходимы успешные проверки всего PR.
