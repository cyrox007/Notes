# Notes 1.2 — устанавливаемая PWA и Web Push

Дата: 20 октября 2026 года. Статус: исходный код для приёмки, **не подтверждена доставка на реальный телефон**.

## Возможности

- `manifest.webmanifest` позволяет предложить установку Notes как приложения с быстрыми переходами к задачам и Messenger. `service-worker.js` обрабатывает фоновые уведомления, **не перехватывает запросы страниц и не кэширует приватные данные**.
- В центре уведомлений появилась секция «Уведомления на этом устройстве». Регистрация выполняется **только после нажатия пользователем**; браузер спрашивает разрешение, затем создаёт подписку с ключами P-256 и передаёт её через авторизованный API с CSRF.
- До пяти браузеров одного пользователя: каждый получает отдельное задание общей очереди. Привязка к другой учётной записи запрещена. Отключение одного устройства не затрагивает остальные. Выход из Notes отзывает текущую привязку, если база доступна.
- Сервис доставки использует стандартные форматы Web Push AES128GCM (RFC 8291) и VAPID ES256 (RFC 8292), ECDH P-256/OpenSSL, проверяемые публичные HTTPS-адреса и TLS, без редиректов. Отозванные Push-сервисом подписки (HTTP 404/410) отключаются.
- Во внешнее уведомление передаются **только идентификатор и безопасный локальный путь**, а на устройстве появляется нейтральный текст. Содержимое задач, переписки и будущих сквозных E2EE-сообщений в запрос не включается.
- При нажатии открывается конкретный раздел сайта. Встроенные события и отправка через другие каналы не зависят от Web Push.

## Начальная настройка VAPID

Создайте отдельный приватный P-256 ключ на доверенном компьютере (PHP/OpenSSL 8.3) и сохраните в защищённом секретном хранилище. Пример вывода **на консоль владельца**, а не в журналы сайта:

```bash
php -r '$k=openssl_pkey_new(["private_key_type"=>OPENSSL_KEYTYPE_EC,"curve_name"=>"prime256v1"]); openssl_pkey_export($k,$pem); echo base64_encode($pem),PHP_EOL;'
```

Задайте переменные окружения PHP, доступные **веб-процессу и обработчику очереди**:

- `NOTES_VAPID_PRIVATE_KEY_BASE64` — Base64 от экспортированного PEM приватного ключа. Не помещать в Git, публичные файлы, SQL, UI или отчёты CI.
- `NOTES_VAPID_CONTACT` — контакт владельца Push, например `mailto:admin@example.org`.
- `SITEURL` и `BASE_PATH` — реальные адрес и префикс установки Notes, согласованные с веб-сервером.

Для включения нажмите «Настройки уведомлений» → «Включить Push» в защищённом HTTPS-сайте, разрешите уведомления браузера, затем включите Browser Push для необходимых категорий. Персональная подписка не создаётся без явного разрешения.

**Ограничения:** сервисный обработчик и Push требуют защищённого контекста HTTPS (обычные `.local` без доверенного HTTPS не подходят). В Android Chrome доступно при поддержке Push; в iOS системный Push поддерживается для установленного на главный экран веб-приложения на совместимых версиях системы. Поведение зависит от разрешений ОС, экономии батареи, браузера и доставщика.

## Подтверждение и отладка

Веб-сервер должен отдавать `manifest.webmanifest`, `service-worker.js` в корне установки и статический `assets/js/pwa-push.js`. Статус API `/api/notifications/push/key` должен возвращать `available: true`; иначе проверьте переменные окружения. API устройств требует активную сессию, а изменяющие команды дополнительно CSRF.

После включения подписки в соответствующей категории инициируйте настоящее событие Notes. В MySQL у каждого устройства должны появиться отдельные строки `notification_delivery_jobs` для канала `browser`, затем `notification_delivery_attempts`. Успех `push_accepted` подтверждает приём Push-сервисом, **не** показ уведомления на экране. Подтвердите показ на заблокированном Android и переход в нужный объект; проверьте также отключение, смену учётной записи, ошибку TLS, устаревший endpoint и очередь после перезапуска.

Автоматические тесты: `notification_web_push_crypto_12.php` (шифрование и заголовки), `notification_web_push_mysql_12.php` (две подписки, изоляция, отзыв, очередь), `notification_pwa_push_12.mjs` (не выходить за пределы сайта, открывать Messenger, без приватного кеша).

## Незакрытые ограничения

- Проверка на реальном устройстве, реальном push-сервисе и рабочем хостинге, включая закрытый браузер и фон, должна быть документирована отдельно.
- Иконка использует исходный SVG-бренд Notes; внешний вид установки зависит от поддержки SVG и маскируемых иконок браузером.
- Показатели «доставлено» из API внешнего сервиса нельзя приравнивать к прочтению пользователем.
- Этот этап **не реализует** одноразовые действия «выполнить задачу» прямо из внешнего уведомления. Они требуют отдельной защищённой команды и проверки версии объекта.
