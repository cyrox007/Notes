# Список проблем доставки для администратора Notes 1.2

## Что изменилось

В разделе **Администрирование → Каналы уведомлений → Ручная приёмка получения** появились две короткие очереди.

**Требуют внимания** — задания с окончательной ошибкой внешнего канала или ручной отметкой «сообщение не найдено». Это первоочередные случаи для разбора оператором.

**Ожидают подтверждения** — задания, успешно принятые внешним каналом (`sent`), но ещё не проверенные оператором. Сам факт принятия сервисом не считается подтверждением получения адресатом.

В каждой очереди показывается не более 20 последних записей. Для просмотра полной истории и фиксации результата нажмите **«История и проверка»**. Номер выбранного задания будет подставлен в форму и не потребует ручного ввода. Для отметки по-прежнему необходимы административное разрешение, защитный токен формы и текущий пароль.

В списки не попадают адреса получателей, содержание уведомлений, настройки каналов и секреты. Исторические записи из других состояний остаются в прежнем разделе «Состояние очереди» и доступны через просмотр по номеру.

## Проверка

Автоматические испытания на MySQL 8.4 и MariaDB 11.4 проверяют разделение ошибок и непроверенных отправок, сортировку, ограничение размера выборки и отсутствие раскрытия персональных данных.

Приложение не отправляет сообщения при просмотре этих очередей. Реальное получение письма или Push требует проверки на контролируемом адресе или устройстве. Не следует отмечать «получено» без такой проверки.

## Эксплуатация

Очередь представляет только ограниченную выборку, а не полный архив доставок. Если ошибок больше 20, старые случаи нужно исследовать через историю и номер задания. Само наличие проблем в списке не отключает канал и не запускает повторную отправку.
