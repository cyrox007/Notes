# Список проблем доставки для администратора Notes 1.2

## Что изменилось

В разделе **Администрирование → Каналы уведомлений → Ручная приёмка получения** появились две короткие очереди.

**Требуют внимания** — задания с окончательной ошибкой внешнего канала или ручной отметкой «сообщение не найдено». Это первоочередные случаи для разбора оператором.

**Ожидают подтверждения** — задания, успешно принятые внешним каналом (`sent`), но ещё не проверенные оператором. Сам факт принятия сервисом не считается подтверждением получения адресатом.

В каждой очереди показывается не более 20 записей на странице. Используйте **«Следующая страница»** и **«Предыдущая страница»**, чтобы открыть старые случаи: страницы двух очередей переключаются независимо. При переходе к **«История и проверка»** сохраняется выбранная страница в каждой очереди. Номер задания автоматически подставляется в форму; для ручной отметки по-прежнему необходимы административное разрешение, защитный токен формы и текущий пароль.

В списки не попадают адреса получателей, содержание уведомлений, настройки каналов и секреты. Исторические записи из других состояний остаются в прежнем разделе «Состояние очереди» и доступны через просмотр по номеру.

## Проверка

Автоматические испытания на MySQL 8.4 и MariaDB 11.4 проверяют разделение ошибок и непроверенных отправок, устойчивую сортировку, навигацию обеих очередей и отсутствие раскрытия персональных данных. Одна страница читает не более 21 строки для определения наличия следующей; значения номера страницы ограничены диапазоном 1–1000.

Приложение не отправляет сообщения при просмотре этих очередей. Реальное получение письма или Push требует проверки на контролируемом адресе или устройстве. Не следует отмечать «получено» без такой проверки.

## Эксплуатация

Очередь предоставляет постраничный обзор, но не является полным архивом доставок. Доступна глубина до 1000 страниц по 20 записей на каждую категорию. Списки изменяются во времени: если между переходами поступили новые события, отдельные записи могут сместиться на соседнюю страницу. Для точного просмотра неизменного номера задания используйте форму поиска по номеру. Само наличие проблем в списке не отключает канал и не запускает повторную отправку.
