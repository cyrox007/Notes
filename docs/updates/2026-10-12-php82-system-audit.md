# Проверка технического минимума PHP 8.2 — 12.10.2026

Ветка: `1.1`. PR: https://github.com/cyrox007/Notes/pull/365.

## Проверки локального окружения

Прогоны выполнены на Windows, с `error_reporting=E_ALL`. Проверены все отслеживаемые PHP-файлы и все 145 файлов `tests/integration/*.php`, включая контракты установщика, обновления/отката, шифрования, прав доступа, модулей, файлов, Notes, Tasks, Messenger, уведомлений и Calendar.

| PHP | Синтаксис: файлов / ошибок | Интеграционные тесты: всего / ошибок | Тестов с Warning, Notice, Deprecated или Fatal |
| --- | --- | --- | --- |
| 8.2.34 | 556 / 0 | 145 / 0 | 0 |
| 8.3.35 | 556 / 0 | 145 / 0 | 0 |

Тесты, меняющие данные, запускались на отдельном экземпляре MariaDB 10.8.4 и одноразовой базе, с отдельным приватным хранилищем и тестовыми ключами. Рабочая база `notes` не использовалась. Полные JSON-результаты сохранены вне репозитория в `C:/OSPanel/audit/php82-20261012`.

Статический аудит 406 файлов рабочего кода: `deprecated=0`, `strict_types_missing=0`, `untyped_properties=0`, `dynamic_property_candidates=0`. Два свойства сокетов документированы как resource; PHP не предоставляет для них тип свойства `resource`.

## Исправления

- Порог запуска WebSocket приведён к PHP 8.2. Документация актуального минимума согласована с Composer, установщиком и healthcheck.
- Провайдеры связей Calendar с Files, Notes и Tasks подключаются к БД при запросе данных, а не при сборке модулей.
- Восстановлены проверки после переноса кода в ApplicationEntryPoint, CliRuntime и сервисы установщика/обновления. Ожидания модулей учитывают Calendar.
- Исправлены Windows-проверки путей, CRLF, TCP-пары сокетов, завершения процесса и удаления SQLite-файлов после освобождения соединений. Сигнатуры тестового Request согласованы с типизированным ядром.
- Матрицы текущего кода переведены с 8.1 на 8.2; исторические сценарии обновления `1.0.x` сохранены. Добавлена отдельная Windows PHP 8.2 проверка критических контрактов. Проверка минимального PHP включена в матрицу 8.2/8.3 и сканирует также модули.
- Включено исправление диапазона повторений Calendar: предшествующие экземпляры возвращаются только при явном окне пересечения. Добавлена проверка границ и недопустимых окон.

## Сохранение веток

В историю включены оставшиеся ветки Calendar: `feature/1.1-calendar-reminders-20261011`, `fix/1.1-calendar-recurrence-range-20261011`, обе ветки браузерного жизненного цикла. Ранние версии браузерных тестов не заменяют более новые исправления в `1.1`.

Локальная `codex/1.0.16-native-messenger-media` также включена в историю; её ограничения времени уже присутствовали в более новой реализации `1.1`, которая сохранена. Удаление завершённых веток допускается только после проверки их вхождения в опубликованную `1.1`.

## Границы результата

Браузерные сценарии, HTTP-установка и MySQL 8.4 выполняются отдельными заданиями GitHub Actions этого PR; их фактический статус следует проверять по PR. Этот аудит не заменяет нагрузочное тестирование и не объявляет линию `1.1` стабильным релизом.
