# Старт разработки 1.2 — 17 октября 2026

Рабочая линия `1.2` открыта от актуального состояния ветки `1.1` после выпуска `v1.1.0`, накопительного патча r2 и фиксации дорожной карты.

## Первый этап

Первый технический этап 1.2 разделён на небольшие проверяемые задачи.

В этом изменении:

- создана интеграционная ветка `1.2`;
- Composer для линии разработки переводится на минимум PHP 8.3;
- добавляется отдельный CI-барьер PHP 8.3 для Linux и Windows;
- системные требования разделяют стабильную 1.1 (PHP 8.2+) и разрабатываемую 1.2 (PHP 8.3.x);
- в обязательный объём 1.2 добавлен Files 1.2 с персональными и глобальными файловыми пространствами и наследуемыми ACL.

Следующая техническая задача после слияния — провести минимум PHP 8.3 через web-установщик, healthcheck, updater/preflight и эксплуатационные сценарии, затем выполнить целевой аудит совместимости 1.2.

## Правила разработки

- визуальный стиль не меняется;
- новые функции идут отдельными рабочими ветками с PR в `1.2`;
- регрессия обновления и восстановления 1.1 сохраняется;
- документация, сообщения проверок и комментарии нового кода ведутся на русском языке, кроме стандартных имён протоколов/API;
- крупные изменения разбиваются на целевые проверки вместо запуска всего набора без необходимости.
