# Предварительный просмотр при ручной приёмке уведомлений

Перед отметкой получения администратор открывает **Каналы уведомлений → Ручная приёмка получения**, вводит номер задания и нажимает «Проверить состояние и попытки».

Экран показывает канал, состояние очереди, время принятия сообщения транспортом, историю попыток и существующую ручную отметку. Все данные берутся из уже существующего обезличенного отчёта, без электронных адресов, текста сообщения и секретов. Просмотр не меняет состояние очереди и не выполняет отправку.

Указанный номер затем можно использовать в форме ниже, но подтверждение получения остаётся отдельным действием с повторным вводом текущего пароля администратора. Доступ к странице защищён существующим административным правом. Если задание не найдено или журнал недоступен, интерфейс сообщает об этом, не раскрывая внутреннюю ошибку.

Даже успешное состояние очереди `sent` не означает фактическое получение: администратор должен проверить контролируемый ящик или устройство самостоятельно.
