# Notes 1.2 — службы и исполнители дефекта

## Что изменено

В открытой карточке дефекта администратор с разрешением `defects.manage` может назначить собственное ФИО исполнителя каждой ответственной службе, снять службу или добавить другую. Пустое ФИО означает «служба назначена, исполнитель не определён».

Изменение списка служб и ФИО выполняется одной транзакцией. Требуется точная версия карточки; одновременные изменения возвращают HTTP 409, после чего следует перечитать карточку. Повтор той же команды с теми же данными возвращает ранее созданную версию без повторной записи в историю. Повтор идентификатора команды с другим содержимым отклоняется.

История сохраняет предыдущее и новое распределение ответственности, версию, учётную запись автора и идентификатор операции. Закрытую карточку изменять нельзя. Обычным пользователям редактор не показывается; сервер дополнительно проверяет право `defects.manage`.

## База данных

Новая миграция `20261028_defects_service_executor.sql` добавляет поле `executor_name` в существующую таблицу `defect_responsible_services`. Отсутствие исполнителя представлено значением `NULL`. Данные и состав служб существующих карточек миграция не удаляет.

Нельзя вручную повторно запускать эту миграцию на базе, где она уже применена: запись об исполнении должна поддерживаться штатным журналом миграций. Перед обновлением действующей системы обязательна резервная копия.

## Проверки

```bash
php tests/integration/defects_service_assignments_12.php
php tests/integration/defects_registration_12.php
php tests/integration/defects_module_runtime_12.php
node --check modules/defects/assets/defects.js
```

Браузерный контур дополнительно проверяет сохранение назначений через HTTP, отказ при устаревшей версии и запрет изменения обычному пользователю.

## Что остаётся до закрытия #537

Отдельно необходимы административное исправление остальных полей, контролируемое архивирование дефекта, полная приёмка ролей и сверка каждого пункта исходного ТЗ. Наличие этого изменения само по себе не подтверждает готовность релиза 1.2.0.
