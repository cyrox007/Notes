# Накопительный патч r2 для Workspace Organizer 1.1.0

Версия остаётся **1.1.0 / 11000**, минимум PHP 8.2. Патч включает все изменения r1; его можно установить поверх исходной 1.1.0 или поверх r1. Это обычный архив изменённых файлов, подпись и сервер публикации не нужны.

В r2 исправлен отступ содержимого и шапки после переходов по свёрнутому боковому меню. Состояние меню согласуется с оболочкой до показа новой страницы, включая историю браузера и смену ширины окна. Тёмные поверхности мессенджера используют общие серые цвета Workspace. В формах события и временного блока календаря часовой пояс выбирается из списка; сохраняются автоматический выбор пояса браузера и существующие идентификаторы IANA.

Сначала завершите активное обновление, сохраните резервную копию файлов сайта и временно закройте доступ пользователям. Распакуйте `workspace-organizer-1.1.0-patch-r2.zip` отдельно. Скопируйте содержимое поверх корня существующего сайта с заменой файлов и объединением каталогов. После копирования обновите страницу Ctrl+F5. Миграции выполнять не нужно.

Патч не содержит `core/Version.php`, `.env`, ключей, `.osp`, SQL или пользовательских данных. Manifest `PATCH_1.1.0_r2.json` перечисляет файлы и их SHA-256. Для отката восстановите заменённые файлы из резервной копии и удалите добавленные пути по manifest.

Префиксы таблиц этим патчем не добавляются. Две установки пока нельзя безопасно размещать в одной БД: установка, миграции, резервное копирование и восстановление ещё не изолированы префиксом. Не задавайте произвольный `DB_PREFIX` в `.env` и не переименовывайте таблицы вручную — приложение пока не учитывает этот параметр.
