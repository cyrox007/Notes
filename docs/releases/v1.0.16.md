# Workspace Organizer 1.0.16

Дата подготовки: 10 октября 2026. Код версии: `10016`.
Статус: кандидат выпуска; публичный релиз и stable-feed ещё не опубликованы.

## Обновление и восстановление

Полный updater repair r4 включён в приложение: проверка идентичности stage по manifest и подписи, корректная обработка generated-колонок, внешний HTTP runtime для Windows, сохранение окружения Apache и расширенный журнал транзакций и восстановления. Отдельно накатывать патчи на установленную 1.0.16 не требуется.

Основной проверяемый переход — 1.0.15 → 1.0.16. Установка 1.0.15, уже исправленная полным repair, использует обычную кнопку обновления. Для исходного повреждённого updater 1.0.13–1.0.15 остаётся исторический полный repair; он сохраняет версию приложения, `.env` и данные. Публикация нового пакета сама по себе не исправляет исполнитель обновления, который ещё работает в старой установке.

## Интерфейс и задачи

- Тёмная тема по палитре VS Code Dark 2026 Default Dark: графитовые поверхности и согласованные состояния кнопок, полей, навигации и уведомлений.
- Восстановлены стили кнопок категорий и подзадач.
- Прогресс подзадач обновляется без перезагрузки после добавления, отметки и удаления, включая динамически созданные подзадачи; ошибка сохранения возвращает прежнее состояние.
- После переноса карточки снимается прозрачность; ошибка сохранения возвращает карточку и счётчики.
- Подсказка «Переместить сюда» и рамка больше не переставляются и не мигают при движении внутри зоны.
- Файл можно перетащить в карточку вложений заметки. Поддерживается один файл за раз, автоматическая загрузка, подсветка области и повтор после ошибки.

## Messenger и голосовые заметки

- Аудио- и видеозвонки один на один с собственной HTTP-сигнализацией Notes, проверкой участников, CSRF, таймаутами и завершением медиапотоков.
- Видеосообщения с предпросмотром, скачиванием и повторной отправкой сохранённой записи.
- Голосовые сообщения ждут подтверждения сервера. Повтор отправки того же вложения не создаёт дубль.
- Локальная расшифровка голосовых сообщений и вложений заметок с выбором языка, редактированием и явной вставкой в черновик.

Новые сторонние библиотеки, SDK, облачное распознавание, внешние STUN/TURN и сервисы сигнализации не используются.

## Практические ограничения

Расшифровка требует поддержки локального распознавания и установленного языка в браузере. Собственная модель распознавания Notes не входит в этот кандидат. Если локальный движок недоступен, аудио не передаётся внешнему сервису.

Звонки используют прямое соединение без ретранслятора; часть сетей с NAT или строгим межсетевым экраном несовместима. Собственный ретранслятор и групповые звонки не входят в выпуск. Для камеры и микрофона браузеру нужен защищённый контекст.

## Приёмка

Перед публикацией должны пройти CI финальной ревизии, проверка перехода 1.0.15 → 1.0.16 с сохранением данных, проверка архивов и SHA-256/source SHA, production-подпись manifest и проверка канала. Реальные устройства, русская речь и звонки между разными сетями требуют отдельной эксплуатационной проверки. Синтетические браузерные тесты не подтверждают точность распознавания.

Технические сведения: `docs/updates/1.0.16-native-fixes.md` и `docs/updates/1.0.16-native-media.md`.
