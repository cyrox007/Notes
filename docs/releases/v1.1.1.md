# Workspace Organizer 1.1.1

Патч для установленной 1.1.0. Дата: 15 октября 2026; код версии **11001**, минимум PHP **8.2.0**.

В тёмной теме календарь, ежедневник, формы и связи используют спокойные тёмно-серые поверхности общей палитры вместо ярких белых блоков. Исправлено краткое сжатие профиля при показе/скрытии материалов: стили страницы активируются вместе после загрузки. Исполнитель обновлений 1.1.1 сохраняет настройки проекта Open Server в каталоге `.osp` при последующих установках и откатах.

Переходы между разделами и обычные действия главной, заметок, задач, календаря, файлов, профиля, мессенджера и админки выполняются без перезагрузки оболочки. Сохраняются серверные проверки сессии, прав, CSRF и CSP, история и положение прокрутки. Несохранённые изменения требуют подтверждения ухода; отправка данных и загрузка файла удерживают страницу до результата.

Модальные окна плавно закрываются, возвращают фокус и корректно обрабатывают Escape, повторное открытие и настройку уменьшения движения. При смене раздела очищаются обработчики, таймеры, временные элементы и соединения мессенджера. Исправлена готовность редактора перед сменой URL. Скачивания, вход/выход, установка обновлений и обновление оболочки после изменения разрешённых модулей используют штатную загрузку браузера.

Обновление устанавливается через **Админ → Обновления** после публикации подписанного выпуска на сайте-сервере. Подготовительный патч для 1.0.16 не нужен. Новых миграций БД нет; .env, ключи и пользовательские данные сохраняются штатным обновлятором с резервной копией и откатом.

Для Open Server и установки 1.1.0 без `schema_migrations` сначала загрузите дополнительный `prepare-1.1.1.php` в корень сайта, откройте под суперадминистратором и примените подготовку. Она обновляет только исполнитель, сохраняя 1.1.0, настройки и БД; затем удалите файл и установите подписанную 1.1.1 через админку. На обычном хостинге с журналом миграций дополнительная подготовка не требуется. На локальной установке эти исправления уже применены.

Параметры публикации: версия **1.1.1**, код **11001**, минимальный исходный код **11000**, PHP **8.2.0**, канал **stable**. ZIP приложения до подписи на сайте издателя не является готовым offline-пакетом для загрузки в админку. Для offline-установки используйте сформированный сайтом пакет с manifest.json, manifest.sig и ZIP приложения.

Нагрузочное тестирование остаётся в плане 1.2.0.
