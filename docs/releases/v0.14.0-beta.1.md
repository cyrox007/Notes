# Workspace Organizer 0.14.0-beta.1

Первый официальный beta-релиз усиления безопасности после функционально завершённой alpha-версии 0.13.

## Что фиксирует beta.1

- усилены границы Router/session/redirect и добавлены security regression contracts;
- формализованы manifests модулей и registry с проверкой compatibility/dependency/capability;
- добавлен persisted lifecycle модулей с configured/effective state и безопасными dependency-aware transitions;
- добавлены каноническая lifecycle schema/upgrade path и fresh-install contract;
- полный baseline HTTP/browser/installer/security regressions, включая authenticated HTTPS/WSS reconnect/realtime smoke;
- корректный lifecycle reconciliation WebSocket runtime без наследования устаревшего DB connection между process boundaries.

## Важная граница beta

Это **beta**, а не `1.0.0`: legacy `app/*` и централизованная route registration ещё мигрируют за module-owned runtime boundaries. Подписанный updater/recovery, licensing, observability/load/soak evidence, transactional key re-encryption и CSP cleanup остаются blockers следующего этапа.

После публикации этой версии основная разработка идёт к **`1.0.0` stable**. При необходимости исправления beta публикуются как `v0.14.0-beta.N` без открытия нового feature cycle.
