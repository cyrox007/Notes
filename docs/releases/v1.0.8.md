# Workspace Organizer 1.0.8

Дата релиза: 29 сентября 2026  
Статус: stable  
Код версии: `10008`

## Назначение релиза

`1.0.8` — небольшой patch-релиз линии 1.0 после успешной реальной проверки обновления `1.0.6 → 1.0.7` на Open Server 6+.

Релиз исправляет визуальный дефект Messenger: когда у пользователя ещё нет чатов, подпись «Диалогов пока нет» отображалась слишком низко, потому что пустой контейнер списка продолжал занимать всё доступное место.

## Что изменено

### Messenger

- пустой список диалогов скрывается, когда действительно нет ни одного чата;
- блок «Диалогов пока нет» занимает свободную высоту левой колонки и центрируется по ней;
- поиск и отображение существующих диалогов остаются без изменений;
- добавлен автоматический контракт на корректное пустое состояние.

## Совместимость

- минимальный PHP: 8.1;
- схема БД и миграции не меняются;
- формат пользовательских данных не меняется;
- обновление выполняется штатным встроенным updater без ручных действий;
- основной проверяемый переход: `1.0.7 → 1.0.8`.

## Проверка релиза

Перед публикацией проверяются:

1. контракт Messenger на центрирование пустого состояния;
2. полный Stable release gate;
3. сквозное подписанное обновление `1.0.7 → 1.0.8`;
4. сохранность существующего updater/recovery-контракта.

## Граница поддержки

`1.0.8` сохраняет compatibility contract линии 1.0 и не требует новых миграций или ручного bootstrap.

Опубликованные теги `v1.0.7` и более ранних версий не перемещаются и не переписываются.
