# Патч ЖНДР и «Дефектов» для Notes 1.2.0-rc.1

**Состояние: готовится; не устанавливать на рабочий сайт до проверки применения.**

Дата обратной связи: 14 ноября 2026 года. Связанные задачи: #566, #567, #568. Исходная ветка: `fix/1.2-release-preparation`, изменения патча: `patch/1.2-feedback-20261114`.

## Принцип

Патч предназначен для установленного релиз-кандидата **без повышения номера версии** приложения или модулей. Он не создаёт миграции БД, не сбрасывает настройки и не требует удаления прежней установки. Номер версии сам по себе **не является доказательством совместимости**: перед применением нужно сверить исходный состав файлов и контрольные суммы с основанием сборки.

Пока отсутствует проверенная процедура применения поверх конкретной установленной сборки, патч **не публикуется как готовое обновление**. Штатный подписанный механизм обновлений не следует обходить подменой неподписанного ZIP. Сведения об установке и безопасном откате будут добавлены после проверки по #568.

## Изменения, которые уже определены

- «Дефекты»: расширена боковая форма регистрации и просмотра, увеличено пространство для описания выполненных работ и комментария, сохранён контраст кнопки при наведении и работе с клавиатурой.
- ЖНДР: название «Журнал нарядов допусков и распоряжений»; номер версии модуля не повышается.
- ЖНДР: отдельные адреса для **документов**, **журнала выдачи** и **справочников/шаблонов**. Старая ссылка остаётся рабочей. Управляющие разделы закрыты для пользователей без права управления.
- Дополнительная автоматическая проверка настоящего браузера, прав доступа и геометрии экранов.

## Изменения, которые пока не выполняются

По технологическому процессу оформление наряда должно быть упрощено: исходная карточка, бригада, условия и отдельные указания должны заполняться согласованным образом до выдачи. Не все реквизиты должны переноситься на компьютер: часть записей остаётся рукописной.

Для реализации ожидается макет Word и примеры текущей диспетчерской системы. PDF должен точно повторять **утверждённый стандартный бланк**, а поля электронной формы должны попадать в соответствующие позиции. Существующий произвольный отчёт PDF не считается выполнением этого требования. Без проверенного образца не изменяем правила заполнения и обязательные реквизиты. Это задача #567.

## Особое предупреждение об обновлении

В полевом сообщении есть случай, когда оператор не разобрался с обновлением через консоль из-за нечитаемых русских символов и переустановил приложение. Для патча **нельзя** предлагать удаление рабочей установки. Задача #568 предусматривает диагностику кодировки, резервное копирование, проверку существующих данных, совместимость с прежней версией и отработанный откат.
