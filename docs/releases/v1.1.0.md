# Workspace Organizer 1.1.0

Выпуск от 13 октября 2026. Минимум PHP 8.2; код версии 11000.

Включает личный Calendar: день, неделю, месяц, ежедневник, события, повторения, временные блоки, часовые пояса и связи с задачами, заметками и файлами. Повторяющееся событие изменяется или удаляется целой серией.

Общий центр уведомлений поддерживает непрочитанные сообщения, настройки подписок, встроенную доставку и SMTP, повторные попытки и восстановление после простоя. Операционные события доступного/установленного обновления, подтверждённого отката, ошибки healthcheck и нехватки места сохраняются вне БД и доставляются действующим администраторам. Приватные диагностические данные в сообщение не включаются.

Чистая установка включает таблицы уведомлений. Для обновления с 1.0.16 учтён опубликованный набор миграций; обновление и восстановление проверяются отдельными сценариями с сохранением данных. Предыдущий аудит PHP 8.2/8.3 закреплён в CI.

Общие календари, исключения отдельных экземпляров серии, импорт/экспорт, Push, Telegram, Webhook и SMS не входят в первый выпуск. Нагрузочная приёмка перенесена на 1.2.0; способность обслуживать 1000 активных пользователей пока не подтверждена.

Выпуск опубликован как GitHub Latest по решению владельца проекта. Для перехода с 1.0.16 сначала установите прилагаемый мост обновлятора из отдельного распакованного пакета. GitHub Release не заменяет подпись manifest и приёмку стабильного feed: этот этап выполняется отдельно в издательской системе. Инструкция: [обновление и возврат](1.1-UPGRADE.md).


Для обновления с 1.0.16 скачайте основной `workspace-organizer-v1.1.0.zip` и `workspace-organizer-v1.1.0-updater-bridge.zip`. Распакуйте основной ZIP отдельно от рабочей установки, затем архив моста в корень распакованного пакета (где находится `core/`). Запустите `php tools/release/bootstrap-1.0.16-updater.php --yes --root=/путь/к/1.0.16` на PHP 8.2+. После этого создавайте и устанавливайте подписанное обновление обычным способом.
