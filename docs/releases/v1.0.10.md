# Workspace Organizer 1.0.10

Дата релиза: 29 сентября 2026  
Статус: stable  
Код версии: `10010`

## Назначение релиза

`1.0.10` — небольшой patch-релиз после `1.0.9`, который закрывает четыре пользовательских хвоста: неверное визуальное состояние Messenger при рабочем Long Poll, щель layout при свёрнутой боковой панели, смещение специализированных Messenger-модалок и лишние legacy-assets в новых GitHub Release.

## Messenger

- Long Poll остаётся основным обязательным транспортом.
- Пока Long Poll работает, Messenger показывает обычное состояние «В сети».
- Фоновое подключение или переподключение WebSocket больше не показывается как ошибка, fallback или действие «Повторить».
- WebSocket сохраняется как необязательный ускоритель и после успешной авторизации бесшовно заменяет Long Poll.
- Если деградирует уже сам Long Poll, пользователь по-прежнему видит состояние восстановления синхронизации.

## Свёрнутая боковая панель

- Desktop sidebar и основной layout теперь используют единое состояние collapse.
- При сворачивании `wrapper__content` сразу переключает левый отступ с `--ui-sidebar` на `--ui-sidebar-collapsed`.
- Между узкой панелью и шапкой/контентом больше не остаётся пустой вертикальной полосы.
- Состояние корректно восстанавливается из `localStorage` и сбрасывается при переходе в мобильный режим.

## Геометрия Messenger-модалок

- Форма создания задачи/заметки больше не имеет отдельную ширину, меньшую ширины внешнего `<dialog>`.
- Ширину задаёт только общий `.messenger-dialog-modal`; специализированные workspace/group/storage-классы больше не переопределяют её локальным `width:min(...)`.
- Внутренний surface всегда занимает `100%`, поэтому форма и native dialog используют один box-model и не смещаются относительно друг друга.

## GitHub Release

Устаревший `bootstrap-1.0.2-updater.php` больше не публикуется. Для перехода с опубликованного `v1.0.9` добавлен отдельный точечный мост совместимости:

- `bootstrap-1.0.9-updater.php`;
- `bootstrap-1.0.9-updater.php.sha256`.

Штатный набор остальных assets:

- `workspace-organizer-v1.0.10.zip`;
- `workspace-organizer-v1.0.10.zip.sha256`;
- `workspace-organizer-v1.0.10.zip.source-sha`.

Ссылки GitHub `Source code (zip)` и `Source code (tar.gz)` создаются самой платформой GitHub для тега и не являются отдельными assets Workspace Organizer.

## Обновление

Глобальная кнопка «Обновить» в центре уведомлений использует тот же пошаговый web-updater, что и страница Admin: повторно проверяет подписанный feed, запускает `web-start-latest` и продолжает транзакцию короткими HTTP-шагами. Это исключает зависание в maintenance/503 на shared hosting.

Основной проверяемый путь — `1.0.9 → 1.0.10` через точечный bootstrap совместимости и затем встроенный подписанный updater.

- Исходной точкой служит опубликованный неизменяемый тег `v1.0.9`.
- В `v1.0.9` список автономного rollback-runtime не включает `core/HostingCompatibility.php`, хотя `Environment.php` уже требует этот файл. Поэтому прямое обновление непатченной 1.0.9 может сорвать автоматическое восстановление после неудачной установки.
- Перед первым обновлением с exact 1.0.9 оператор один раз запускает `php bootstrap-1.0.9-updater.php --yes --root=/path/to/workspace`. Bootstrap не устанавливает пакет и не обходит подпись: он только атомарно исправляет список файлов updater-runtime.
- После bootstrap обновление продолжается обычной кнопкой через встроенный подписанный updater. Повторный запуск bootstrap безопасен и ничего не меняет.
- Схема БД и формат пользовательских данных не меняются.
- Распаковка ZIP поверх рабочей установки не является поддерживаемым способом обновления.

## Совместимость

- PHP: 8.1+.
- БД: MySQL 8.0+ или MariaDB 10.5+.
- WebSocket не является обязательной зависимостью Messenger.
- Windows / OSPanel 5.2.2 и OSPanel 6+ остаются целями ручной релизной приёмки.
