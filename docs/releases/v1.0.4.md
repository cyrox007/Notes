# Workspace Organizer 1.0.4

Дата релиза: 24 сентября 2026  
Статус: stable  
Код версии: `10004`

## Состав релиза

`1.0.4` — исправляющий релиз для проверки и эксплуатации штатного контура обновлений после `1.0.3`.

Основные изменения:

- компактный интерфейс Admin → Updates без крупных служебных блоков и лишней вертикальной высоты;
- исправленный поиск PHP CLI в Windows/OSPanel: сначала рядом с фактическим web-бинарником, затем в абсолютных каталогах `PATH`;
- сохранён fail-closed режим: если пригодный CLI действительно не найден, установка из браузера остаётся недоступной;
- сквозная проверка обновления начинается с exact опубликованной `v1.0.3` и устанавливает текущий `1.0.4`;
- после перехода на `1.0.4` тот же стенд проверяет следующую подписанную установку из Admin UI;
- схема БД в этом patch-релизе не меняется.

## Совместимость

- Минимальная исходная версия штатного обновления: `1.0.3 (10003)`.
- PHP: 8.1+; для публичного production рекомендуется поддерживаемая ветка PHP, сейчас 8.3+.
- MySQL: 8.x.
- Existing install обновляется только через подписанный updater; распаковка ZIP поверх рабочей установки не считается штатным обновлением.

### Установки 1.0.2

Прямой переход `1.0.2 → 1.0.4` не является поддерживаемым. Опубликованная `1.0.2` сначала должна перейти на `1.0.3` через `bootstrap-1.0.2-updater.php`, предназначенный только для exact `1.0.2 (10002)`. После успешного перехода `1.0.3 → 1.0.4` выполняется обычным подписанным updater.

## Что проверяем этим релизом

Основная ручная проверка для Windows/OSPanel:

1. чистая установленная и активированная `1.0.3`;
2. Admin → Updates должен обнаружить PHP CLI без ручного `UPDATE_PHP_BINARY`, если `php.exe` находится рядом с активным web-PHP или доступен через абсолютный каталог `PATH`;
3. после публикации подписанного `1.0.4` кнопка установки должна пройти staging, backup, candidate, live apply, миграции и post-update healthcheck;
4. после перезагрузки интерфейс показывает `1.0.4`, а транзакция имеет состояние `committed`.

Доступ к feed и пакету по-прежнему проверяется отдельно от механизма live apply; реальная связка с control plane `jsint-site` подтверждается ручным тестом установленной `1.0.3` против опубликованного stable-релиза.

## Граница перед 1.1.0

`1.0.4` не открывает feature-cycle. Изменения ограничены интерфейсом обновлений, совместимостью Windows/OSPanel и доказательством штатного update-path.
