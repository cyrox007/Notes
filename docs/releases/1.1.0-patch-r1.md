# Патч r1 для Workspace Organizer 1.1.0

Версия приложения после установки остаётся **1.1.0 / 11000**. Патч содержит только изменённые файлы; подпись и сервер публикации обновлений не требуются.

Исправления: AJAX-переходы и действия модулей, плавное закрытие модальных окон, тёмно-серые поверхности календаря, краткое сжатие профиля при показе/скрытии материалов, сохранение `.osp` при последующих обновлениях и распознавание опубликованной схемы 1.1.0 без журнала миграций.

Сохраните резервную копию файлов сайта, завершите активное обновление и временно закройте сайт для пользователей. Распакуйте архив отдельно, затем скопируйте его каталоги `app`, `assets`, `core`, `modules` и остальные указанные в manifest пути **поверх** существующего корня сайта с заменой файлов. Объединяйте каталоги, не удаляйте их перед копированием. После этого откройте сайт и обновите страницу Ctrl+F5.

В архиве нет `core/Version.php`, `.env`, ключей, `.osp`, пользовательских файлов или SQL. Миграции выполнять не нужно. Для отката верните сохранённые версии заменённых файлов; новые пути перечислены в manifest патча.

Локально исправления уже установлены и конфигурация Open Server восстановлена. Отдельная версия 1.1.1 не выпускается.
