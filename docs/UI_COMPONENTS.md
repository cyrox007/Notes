# Общие компоненты интерфейса

Общие правила находятся в `assets/css/workspace.css`, базовые поля — в
`app/views/core/controls.css`. Модуль задаёт расположение элементов, а не свои
цвета, высоты и анимации контролов.

Для формы или контейнера форм используйте `ui-form`. Текстовые поля, даты,
select и textarea получают общие размеры, фон, границы, подписи и focus.
Checkbox/radio сохраняют собственный компактный размер; multiple-select
отличается от обычного select. Ошибки обозначаются `aria-invalid="true"`,
недоступные поля — `disabled`, поля чтения — `readonly`.

Кнопки и ссылки-действия используют базовый класс `ui-button`:

| Вариант | Класс |
|---|---|
| Основное действие | `ui-button--primary` |
| Вторичное действие | `ui-button--secondary` |
| Опасное действие | `ui-button--danger` |
| Без фона | `ui-button--ghost` |
| Компактная / крупная | `ui-button--small` / `ui-button--large` |
| Только иконка | `ui-button--icon` плюс обязательный `aria-label` |

Общие состояния: hover, active, focus-visible, disabled, aria-disabled,
aria-busy, aria-pressed; анимация отключается при prefers-reduced-motion.
Динамически создаваемые кнопки должны получать те же классы, что серверная разметка.
Не помещайте кнопку в label другого поля: действие должно быть соседним элементом.

Аккордеоны новых модулей и общих файлов используют обработчик в
`assets/js/usability-actions.js`. Он анимирует настоящую высоту в обе стороны,
поддерживает повторный клик и очищается при AJAX-переходе.

Проверки реальных PHP-шаблонов: `tests/e2e/module-motion.mjs` и
`tests/e2e/shared-components.mjs`.
