## Состав выпуска

### Messenger

- объединены исправления компактной ширины из #314/#315;
- восстановлены реальные аватары;
- имя и аватар личного собеседника ведут в его профиль;
- исправлен публичный профиль;
- Long Poll остаётся полноценным рабочим транспортом;
- проверка самовосстановления согласована с отображением активного транспорта.

### File Manager

- центр «Общий доступ» показывает созданные ссылки и их состояние;
- активную ссылку можно скопировать, открыть, ограничить сроком или отозвать;
- отзыв не удаляет исходный объект;
- поддержана публикация папки одним URL с безопасной навигацией только внутри опубликованного дерева;
- папка открывается кликом по всей карточке;
- максимальный размер одного файла настраивается через Admin;
- Admin диагностирует конфликт лимита Workspace с PHP и известным пределом веб-сервера и показывает руководство по исправлению.

### Profile

- добавлен каталог пользователей с поиском и постраничным выводом;
- каталог и Messenger ведут в профиль пользователя;
- настройки собственного профиля используют термин «Видимость профиля»;
- видимость профиля отделена от ссылок общего доступа File Manager.
