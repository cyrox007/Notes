# Статус релизной линии Workspace Organizer 1.0.x

> **Обновлено 9 октября 2026.** Текущая опубликованная стабильная версия — **1.0.14**. **1.0.15** объединяет исправления и внешний runtime updater и выпускается как предварительный релиз после зелёного CI итоговой ревизии. Публичный stable-feed автоматически не переключается.

## Workspace Organizer 1.0.15 — предварительный выпуск сопровождения

- версия: `1.0.15`;
- код версии: `10015`;
- статус приложения: `stable`;
- исходные PR: #337 (пользовательские исправления), #339 (внешний runtime updater); итоговая сборочная ветка: `codex/prepare-1.0.15-release`;
- основной путь обновления: `1.0.14 → 1.0.15` через **Admin → Updates**;
- проверенный путь с 1.0.14 требует предварительного CLI-моста из доверенного exact-пакета 1.0.15;
- переустановка с нуля не считается доказательством upgrade-path;
- тёмная палитра 1.0.14 остаётся без изменений до отдельного решения.

Для предварительного выпуска обязательны: exact upgrade с `v1.0.14` после CLI-моста, сохранность пользовательских данных/private storage, зелёный File Manager lifecycle, BASE_PATH hardening, Stable release gate и остальные обязательные проверки итоговой ревизии.

До перевода в стабильный канал остаются подписанный браузерный bootstrap без CLI, согласованный возобновляемый backup БД, ограничения больших операций, recovery во время частичной замены live-кода, реальная hosting-приёмка и production-подпись/канал. Подробности: `docs/UPDATER_RESUMABLE_WORK_2026-10-09.md`. Автоматическая публикация контролируется `.github/release-readiness.json`.

## Основные исправления 1.0.14

- устранено зависание maintenance после уже подтверждённого `rollback_verified` или `committed`;
- исправлена инициализация `schema_migrations` для опубликованных установок, где журнал ещё отсутствовал;
- пофайловая замена и rollback инвалидируют OPcache там, где функция доступна;
- rollback и recovery сохраняют безопасный диагностический код первичной ошибки;
- добавлены сервисный журнал и обезличенный диагностический ZIP;
- суперадминистратор может отправить диагностический ZIP напрямую в активированный JSInteractive control plane и получить `diagnostic_id`;
- обновлён брендовый интерфейс Workspace Organizer, включая светлую/тёмную тему, общий shell, нижнюю информационную строку и оформление публичного аватара.

## Переход с 1.0.12 и 1.0.13

Опубликованные 1.0.12 и 1.0.13 содержат ранний web-updater, который нельзя полностью исправить только содержимым целевого ZIP. Поэтому перед первым переходом на 1.0.14 выполняется доверенный мост:

```bash
php tools/release/bootstrap-1.0.12-updater.php --yes --root=/path/to/workspace
```

После него обновление выполняется штатно через **Admin → Updates**. Ручной SQL, выборочное копирование PHP-файлов и редактирование `.env` не требуются.

## Workspace Organizer 1.0.13 — исторический снятый выпуск

`v1.0.13` опубликован 30 сентября 2026 и остаётся неизменяемым историческим тегом, но снят с публичного stable-feed после эксплуатационного дефекта web-only updater. Его артефакт сохраняется как поддерживаемая исходная точка перехода на 1.0.14 через совместимый updater-handoff.

## После публикации GitHub Release

Эксплуатационный ввод 1.0.14 завершается на стороне JSInteractive:

1. зарегистрировать `v1.0.14` и её неизменяемые артефакты в реестре релизов;
2. установить `min_source_version_code = 10012`;
3. подписать и опубликовать stable-feed;
4. убедиться, что лицензированная установка видит 1.0.14;
5. выполнить контрольный переход с опубликованной 1.0.12 или 1.0.13 через handoff и штатный web-updater;
6. при проблеме использовать **Admin → Обновления → Диагностика поддержки** и отправить обезличенный пакет разработчику.
