# Историческое имя документа

Этот путь сохранён для старых ссылок. Актуальные системные требования находятся в [SYSTEM_REQUIREMENTS.md](SYSTEM_REQUIREMENTS.md).

Требования, сформулированные для 0.14 beta, не являются самостоятельным источником истины для линии 1.0.x.


## Совместимость старых проверок

Технический минимум стабильной линии 1.0.x: **PHP 8.1+**.

Для необязательного WebSocket-режима на Unix используются возможности process-control; в соответствующей среде применяются расширения `pcntl` и `posix`. Основной HTTP Long Poll и остальные модули не должны зависеть от их наличия.
