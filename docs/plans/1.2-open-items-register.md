## Невлитые и исторические ветки

На дату сверки незавершённых PR **не осталось** после закрытия #442 и объединения #521 (до открытия документационного PR этого обновления). Ветви `feature/1.2-work-permits-pdf-form-audit`, `feature/1.2-work-permits-permissions-briefings`, `feature/1.2-work-permits-print-layout`, `feature/1.2-work-permits-signature-columns` содержат историю уже объединённых этапов и разошлись с `1.2`. Не следует вливать их повторно или делать принудительное обновление: это может вернуть старое состояние. Физическое удаление веток пока не выполнено. `feature/1.2-messenger-notification-outbox` сохраняется только как история закрытого черновика #442. Технические ветви PR #515, #516, #517 и #518 также остаются в GitHub после их объединения; отдельный доступный инструмент удаления веток отсутствует, поэтому они не объявляются удалёнными.
