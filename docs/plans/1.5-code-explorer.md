# 1.5 — CodeExplorer / Workspace IDE

Статус: **запланирован**.

Цель — IDE-подобное рабочее пространство для локальных проектов и репозиториев.

## Базовый объём

- дерево проекта;
- несколько открытых файлов;
- подсветка синтаксиса;
- поиск по файлам и содержимому;
- безопасное редактирование текста;
- diff;
- история файлов;
- клавиатурный сценарий;
- ACL workspace/repository;
- autosave/manual save и восстановление черновиков.

## Git-слой

- обнаружение, создание и импорт репозиториев;
- status, staged/unstaged;
- commit и история;
- branches/tags;
- diff ревизий;
- blame/history navigation;
- облегчённый merge/review;
- локальные репозитории как основной сценарий;
- remote sync как отдельная capability;
- интеграция с Notes/Tasks только через публичные contracts.

## Граница безопасности

Произвольный shell, выполнение кода, build/test runner и удалённые Git credentials **не входят автоматически** в trusted Core. Если такой функционал понадобится, он получает отдельный sandbox, permissions и security design.
