# 1.4 — Общий медиаслой

Статус: **запланирован**.

Это не отдельный «плеер ради плеера», а общий viewer/player contract для Files, Notes, Messenger и будущих модулей.

## Целевой объём

- аудио и видео из разрешённых ресурсов разных модулей;
- встроенный preview без дублирования исходных файлов;
- range requests и потоковая выдача больших файлов;
- сохранение позиции воспроизведения там, где это уместно;
- metadata, duration, thumbnails/covers;
- безопасный media probing;
- очередь/playlist как возможность host-модуля;
- интеграция через capability без чтения чужих таблиц;
- явная декларация поддерживаемых codec/container capabilities.

Полноэкранный медиаплеер может появиться позже как оболочка над тем же API.
