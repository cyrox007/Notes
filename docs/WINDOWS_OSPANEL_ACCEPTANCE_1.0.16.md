# Релизная приёмка Windows / OSPanel для 1.0.16

Проверить обновление исправленной установки 1.0.15 до 1.0.16 штатной кнопкой, без переустановки и ручного SQL. Исходной 1.0.15 с дефектным updater сначала требуется полный repair; повторно применять его к целевой 1.0.16 не требуется.

До установки сохранить проверяемую резервную копию. После установки подтвердить 1.0.16 (10016), завершённую транзакцию, отсутствие maintenance marker и сохранность `.env`, базы, вложений, пользователей, прав и лицензии. Проверить восстановление при сбое; `rollback_failed` должен сопровождаться конкретной причиной и ID транзакции в диагностике.

Проверить тёмную и светлую темы, кнопки Task Manager, несколько переносов карточек, отсутствие мигания подсказки, загрузку файла перетаскиванием и повтор после сетевой ошибки.

В защищённом контексте проверить голосовое и видео, повтор отправки без дубля, завершение звонка и освобождение камеры/микрофона. Проверять локальную расшифровку только при доступном локальном движке и языке; отсутствие поддержки должно показывать объяснение, без сетевого fallback.

Приёмка на реальной Windows/OSPanel и проблемном shared hosting не заменяется успешным CI на Linux.
