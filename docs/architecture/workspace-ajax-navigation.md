# Навигация Workspace без перезагрузки

Обычные переходы и формы в главной, заметках, задачах, календаре, файлах, профиле,
мессенджере и админке используют общую оболочку. Сервер по-прежнему проверяет
сессию, права и CSRF и отдаёт полноценную HTML-страницу; браузер заменяет только
`#main-content`, загружает модульные стили и выполняет разрешённые nonce скрипты.
Существующие JSON API и обработчики отдельных действий сохраняются.

`page-runtime.js` регистрирует инициализаторы страниц и даёт им область жизни:
глобальные обработчики отменяются, таймеры останавливаются, наблюдатели
отключаются, временные DOM-узлы удаляются. Мессенджер закрывает соединение и
останавливает медиа при уходе; очередная страница создаёт свежий экземпляр.
Несохранённый черновик требует подтверждения перехода, незавершённая запись
данных или загрузка файла удерживает страницу до получения результата.

Навигация сохраняет историю и положение прокрутки. POST не повторяется
автоматически при сетевой ошибке. Скачивания, внешние ссылки, вход/выход,
транзакции установки обновлений и изменение доступных модулей после смены
лицензии используют штатную загрузку документа: эти переходы требуют обновить
аутентифицированную оболочку или исполняемый код.

`modal-motion.js` откладывает скрытие модального окна до конца анимации.
Повторное открытие отменяет старое закрытие, повторный запрос закрытия не
дублирует очистку. Обработчики отмены записи сохраняют приоритет; настройка
`prefers-reduced-motion` отключает движение. Фокус возвращается после фактического
закрытия native dialog, фон остаётся заблокирован до этого момента.

Проверки: `ajax-navigation.mjs` покрывает оболочку, формы, CSRF, CSP, историю и
очистку обработчиков; `workspace-ajax-lifecycle.mjs` — реальные действия модулей
на отдельной MySQL-базе; `modal-motion.mjs` — закрытие, Escape, отмену, повторное
открытие, уменьшение движения и восстановление фокуса.
