# Проверка реального применения миграции Tasks 1.2

Испытание `tests/integration/upgrade_tasks_versions_mysql_12.php` применяет файл `20261017_tasks_entity_versions.sql` через платформенный `PrefixMysqli` на MySQL 8.4.

Для пустого и непустого `DBPREFIX` создаются тестовые таблицы задач со структурой до появления поля версии, добавляются записи и дважды выполняется SQL миграции. Проверяется сохранение записей, появление ровно одного поля `version` и его начальное значение 1. Изолированные таблицы удаляются в конце испытания.

Тест входит в workflow `upgrade-11000-12000-preflight.yml`. Он подтверждает фактическое выполнение одного SQL-файла на тестовых таблицах, **не** полный процесс миграции всех модулей опубликованной установки 1.1.0. Для закрытия #425 по-прежнему обязательны полная установка опубликованного тега, переход всех миграций, восстановление после прерывания и испытания на OSPanel/MariaDB.
