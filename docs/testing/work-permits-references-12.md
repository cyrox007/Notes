# Notes 1.2 — справочники для нарядов и допусков

## Что реализовано

Самостоятельный пакет `work-permits` получил четыре отдельных справочника:
организации, подразделения, объекты эксплуатации и сотрудники. Подразделения,
объекты и сотрудники принадлежат выбранной организации; у сотрудника может быть
указано подразделение и группа электробезопасности I–V.

Пользователь с правом `work_permits.use` читает активные записи для заполнения
черновиков. Пользователь с правом `work_permits.manage` через раздел
«Управление справочниками» добавляет, переименовывает, архивирует и
восстанавливает записи. Все изменения сопровождаются записью истории.
Нельзя удалить справочник, который уже использовался в документах.

Выбор при регистрации черновика теперь происходит через выпадающие списки.
**Сервер**, а не браузер, проверяет, что выбранные подразделение и объект
действуют и принадлежат выбранной организации. Идентификаторы сохраняются
в отдельных колонках документа, а названия копируются в черновик.
Переименование справочника не изменяет исторические документы.

У существующих черновиков сохраняются текстовые названия и прежние
идентификаторы повторных команд. Новая миграция добавляет ссылки в
существующую таблицу, не требует заполнения новых полей у старых строк.

## Управление доступом и конкуренцией

- Чтение активных справочников: `work_permits.use`; просмотр архивных и
  изменение: `work_permits.manage`.
- Изменения через HTTP требуют авторизацию, CSRF и проверку права на сервере.
- Переименование, архивирование и восстановление используют ожидаемую
  `version`. Если версия устарела, сервер возвращает конфликт 409.
- Архивный объект нельзя выбрать в новом черновике. Повтор прежней команды
  регистрации черновика остаётся идемпотентным даже после архивирования.
- Для справочников используются ограниченные страницы до 100 записей.
- В браузере названия отображаются безопасно, без выполнения разметки.
- Таблицы нового модуля не доступны другим прикладным модулям напрямую.

## Проверка

```bash
php tests/integration/work_permits_references_mysql_12.php
php tests/integration/module_registry_contract.php
php tests/integration/module_schema_ownership_contract_12.php
node --check modules/work-permits/assets/work-permits.js
```

Сценарий MySQL 8.4 проверяет четыре справочника, права, архивирование,
историю версий, несовпадающую организацию, неизменность снимков названий
и повтор команды после переименования и архивирования. Также проверяются
две страницы реестра при более чем 100 записях.
