# Единая рабочая очередь исполнителя Notes 1.2

На странице **«Мои задачи»** отображается отдельный блок «Моя рабочая очередь». Он загружается асинхронно через защищённый сессионный маршрут `GET /tasks/assignment-queue` с проверкой `tasks.use` и может обновляться без перезагрузки страницы.

В три группы — «Просрочено», «Сегодня», «Завтра» — объединяются личные задачи и задачи, назначенные текущему пользователю на общих досках. Личные задачи показываются только владельцу; командные — только при действующем назначении и доступе к доске. Архивированные и удалённые задачи, закрытые доски и завершённые задания исключаются.

Группы рассчитываются по границам локальных календарных дней, используя текущее время PHP-установки и существующий контракт хранения `DATETIME` без смещения. Для последующей реализации часового пояса конкретного пользователя потребуется отдельный контракт интерпретации исторических сроков; **текущая версия не переводит существующие сроки из локального времени в UTC**.

Для контроля объёма данных за один запрос читается не более 300 записей каждого источника, затем показывается до 30 задач в каждой группе. Поле `has_more` сигнализирует о неполной выдаче. При переполнении верхней границы источника нельзя считать эти 30 записей исчерпывающими. На первом этапе элементы ведут к существующим экранам редактирования личной задачи или соответствующей общей доски.

Проверяется на MySQL 8.4 и MariaDB 11.4: даты, объединение источников, исключение чужих личных задач, сохранение назначений наблюдателю и скрытие задач при отзыве доступа. Продолжение #423: учёт пользовательского часового пояса, полнофункциональные быстрые действия, серверная курсорная выдача, повторные напоминания и живые сводки.
