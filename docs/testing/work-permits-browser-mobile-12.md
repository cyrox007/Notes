# Notes 1.2 — браузерные и мобильные проверки нарядов

## Выполненный этап

Добавлен отдельный процесс CI `.github/workflows/work-permits-browser-12.yml`,
запускающий Chromium с реальными PHP-представлением
`modules/work-permits/views/index.php` и клиентскими скриптами модуля.
Он не заменяет интерфейс самостоятельной нарисованной страницей.

Проверяются действия пользователя в порядке рабочего цикла:
редактирование черновика и состава бригады, выдача с условиями из шаблона,
первичный допуск, перерыв, возобновление в тот же день, окончание дня,
полное окончание работ и закрытие. Дополнительно проверяются ссылка PDF
после закрытия, отправка CSRF при изменениях, восстановление кнопки
после отказа сохранения и ограничение видимости управленческих элементов
для обычного пользователя.

Для экранов 320, 360, 390, 768 и 1440 пикселей автоматически
контролируются ширина документа, видимые элементы за границей окна,
скрытие неактивных форм и ошибки JavaScript. Исправлено правило стилей:
сетка формы ранее могла перекрывать атрибут `hidden`, из-за чего
в неактивном состоянии одновременно показывались чужие этапы.
Добавлены ограничения ширины длинных подписей и карточек на телефоне.

## Как запускать

```bash
npm install --no-save playwright@1.55.0
npx playwright install --with-deps chromium
node tests/e2e/work-permits-browser-mobile-12.mjs
```

При ошибке в CI сохраняются снимки окна и файл диагностики.
Серверные ответы в данном браузерном сценарии моделируются;
настоящие ограничения транзакций, версий и записей проверяются
отдельным `tests/integration/work_permits_condition_templates_mysql_12.php`.
Таким образом, **эта проверка подтверждает работоспособность клиентского
поведения, но не считается полной приёмкой настоящего сайта**.
