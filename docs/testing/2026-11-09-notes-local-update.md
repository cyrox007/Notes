# Фактическое обновление notes.local

9 ноября 2026: локальная 1.1.0 обновлена через админку до подписанной 1.2.0-rc.1 с GitHub Latest. Итоговая транзакция `web-update-20261109-145505-6708580d20` подтверждена внешним журналом; критерий результата — состояние `committed` и открывшийся интерфейс целевой версии, а не один успешный HTTP-ответ.

До начала сделана дополнительная полная копия кода и общей базы вне web-root: `C:/OSPanel/audit/notes-local-startup-20261109/full-backups/before-shared-upgrade-20261109`. Штатный updater также создал свою резервную точку.

Найдены и исправлены:

- Повторные обработчики формы расходовали одноразовую привязку двумя запросами старта. Добавлены синхронная защита формы до confirm и single-flight в общем runner. Проверка браузером с двумя обработчиками и повторными submit прошла; фактическое обновление сделало один запрос старта.
- Исторический порядок INSERT в `schema_migrations` принимался за канонический порядок SQL пакета. В общей базе модули устанавливались независимо. Updater теперь сравнивает порядок уже применённых исходных миграций по исходному и целевому манифестам. При отсутствии исходного манифеста прежняя строгая проверка сохраняется. Неизвестные записи, изменение контрольных сумм и реальная перестановка исходных миграций по-прежнему отклоняются. История БД не переписывалась.
- Открытая по HTTP страница не совпадала с настроенным `SITEURL=https://notes.local`. Установка выполнена по HTTPS; origin-проверка не ослаблена.

Результаты после обновления:

- 9 модулей и 99 таблиц; проверка схемы `ready=true`, отсутствующих таблиц и обязательных пользовательских полей нет.
- Полная копия общей базы восстановлена только в отдельную тестовую БД. Сравнение 58 таблиц пользовательских сущностей с рабочей базой не обнаружило различий. Для users исключены только эксплуатационные timestamps last_login_at, last_seen_at, updated_at. Данные других таблиц сравнивались полностью, включая сообщения, файлы, календарь, дефекты и наряды.
- Все прежние ключи `.env` сохранили значения. Ранее добавленная локальная настройка сосуществования модулей осталась дополнительной строкой.
- Временная испытательная административная сессия удалена; исходная сессия пользователя не использовалась для установки.

Локальные доказательства: `upgrade-main-result.json`, `upgrade-main-final.log`, `business-preservation.json`, `upgraded-main.png` в `C:/OSPanel/audit/notes-local-startup-20261109`. Каталог содержит резервную копию пользовательских данных и не предназначен для публикации целиком.

Подписанный ZIP и его GitHub-тег не менялись. Защита повторного запуска и проверка порядка манифестов применены как локальное исправление и сохранены в исходниках следующего патча.
