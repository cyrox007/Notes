# Notes 1.2 — первый работающий этап модуля «Наряды и допуски»

## Реализовано

Добавлен самостоятельный необязательный модуль `work-permits`, без прямых зависимостей от Tasks, Defects, Calendar и других прикладных модулей.

- Отдельная страница `/work-permits/` с формой регистрации наряда-допуска или распоряжения.
- Только черновики: данные организации, подразделения, объекта и задания.
- Общая сквозная нумерация обоих типов документов из первичного ключа базы данных.
- Личный журнал за последний месяц с серверной постраничной выдачей до 20 записей.
- Серверное право `work_permits.use`, обязательная авторизация и CSRF при изменении.
- Чужие карточки и чужие строки журнала недоступны даже при подборе номера.
- Повтор запроса с тем же `command_id` возвращает прежний документ без второй записи истории; команда с изменённым содержимым отклоняется конфликтом 409.
- Отдельные таблицы `work_permit_documents` и `work_permit_history`, собственная схема, миграция, манифест и capability.
- Новая схема используется при установке пакета, миграция предназначена для существующих баз.
- Интерфейс использует AJAX, состояния загрузки и безопасное отображение данных через `textContent`.

## Граница готовности

Это **первый этап**, а не реализованный полный цикл наряда.
После двух следующих этапов доступны справочники, редактирование черновика и
состав бригады; пока **не работают** шаблоны, выдача, допуск, продление, перерывы, закрытие,
регистрация в общем журнале других пользователей и официальная печать PDF.

Модуль по умолчанию **отключён**; для включения необходима соответствующая
лицензионная возможность `workspace.work-permits` и применение миграций.
Административное право `work_permits.manage` предоставляет операции со справочниками;
управление состояниями выданного наряда пока недоступно.

Наряд, находящийся в состоянии черновика, не является действующим
документом для выполнения работ. UI не предлагает функцию выдачи.

## Проверка

```bash
php tests/integration/work_permits_draft_mysql_12.php
php tests/integration/module_registry_contract.php
php tests/integration/module_schema_ownership_contract_12.php
node --check modules/work-permits/assets/work-permits.js
```

Интеграционный тест на MySQL 8.4 проверяет обе разновидности документов,
автоматический номер, атомарную запись истории, повтор одного запроса,
запрет повторной команды с другим содержимым, изоляцию двух пользователей,
запрет административного права обычному пользователю и курсор на 23 записях.

Справочники, редактирование с контролем версии и состав бригады реализованы
отдельными этапами; далее добавить полный жизненный цикл,
не смешивая всё в единственную таблицу. Основная задача #421 остаётся открытой.
