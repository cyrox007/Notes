# Печатный макет наряда 1.2

Скачивание PDF теперь формирует самостоятельные лицевую и оборотную части с реквизитами, мероприятиями, разрешениями, инструктажами и ежедневными допусками. Графы подписей **остаются пустыми**, поскольку отметки системы не являются личными подписями работников.

**Ограничения:** макет не утверждён организацией, пока не сопоставлен с её бланком. Поле «что должно быть изолировано (ограждено)» пока не имеет отдельного структурированного значения и намеренно не заполняется данными из поля «оставшееся под напряжением». Необходимо дополнить схему, форму и миграцию; подтвердить правильность оборотной стороны, разделов инструктажа и подписей на реальных обезличенных образцах. До этого не использовать PDF как нормативно завершённый документ. #421 остаётся открытой.
