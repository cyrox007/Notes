# Notes 1.2 — раздельная печать и третья графа безопасности

## Реализовано

- Учётный PDF по прежнему доступен по `GET /api/work-permits/{id}/pdf`.
- Отдельный **печатный макет для проверки** доступен по `GET /api/work-permits/{id}/pdf?layout=form`. Оба способа имеют ту же проверку полномочий и принадлежности документа, запрет черновиков/распоряжений и отказ от кэширования.
- В печатном макете лицевая и оборотная части начинаются с разных листов. Отдельно выводятся разрешения на подготовку, индивидуальные инструктажи, рабочие периоды, продления, изменения бригады, окончание и закрытие.
- Линии подписей остаются **пустыми**: события в Notes не дают оснований считать подпись работника проставленной. В каждом PDF сохраняется предупреждение о статусе учётной копии.
- Три графы подготовки рабочего места теперь разделены: электроустановка, отключение/заземление, **изоляция/ограждение**. Сведения об оставшемся под напряжением оборудовании не выдаются за изоляцию. Старые документы содержат пустое/неизвестное значение третьей графы.
- Поле `isolated_parts` добавлено отдельной миграцией `20261025_work_permits_isolation_column.sql` с необязательным значением для старой базы. В новых формах значение указывается явно, включая вариант «Не требуется».
- При повторе выдачи с новыми данными отпечаток команды учитывает `isolated_parts`; ранее записанные команды без этого поля остаются совместимыми.

## Проверки

```bash
php tests/integration/work_permits_print_layout_mysql_12.php
```

Сквозная проверка на MySQL 8.4 сначала выполняет все ранее созданные этапы. Затем проверяет старый наряд без неизвестного ранее поля, новую выдачу с тройкой различных значений, сохранение снимка, безопасный повтор команды и конфликт изменённого запроса. PDF проверяется через Poppler: наличие кириллицы, перенос страниц, самостоятельный оборотный лист, корректность обеих форм и запрет вывода распоряжения как наряда.

## Ограничения и приёмка

Макет **не является утверждённым организацией бланком** и не имеет юридически значимых электронных подписей. Остаётся подтверждение порядка и подписных граф приложения №7 к приказу №903н по принятой организацией форме. Для допуска в эксплуатацию необходимо сравнить распечатки с подлинными утверждёнными и обезличенными образцами, включая многостраничность, продления и условия без отключений, а также провести массовую нагрузку и испытания на физических Android/iOS.

Не объявлять нормативную приёмку завершённой, пока не получено решение ответственного за охрану труда. Задача #421 открыта, релиз 1.2.0 не готов.
