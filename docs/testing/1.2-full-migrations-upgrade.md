# Испытание полного набора миграций 1.1 → 1.2

Workflow `upgrade-11000-full-migrations.yml` получает опубликованный тег `v1.1.0`, создаёт таблицы по контракту установленного состава модулей этой версии, добавляет пользователя и запускает `Core\UpdateDatabaseMigrator::run(false, 11000)` из ветки 1.2.

Контролируется число применённых миграций, отсутствие повторных изменений, полнота журнала и сохранение пользовательской записи. Испытания выполняются отдельно на MySQL 8.4 и MariaDB 11.4 с PHP 8.3, только во временной базе CI.

Ограничение: этот стенд проверяет полный SQL-переход схемы и работу штатного мигратора, но не выполняет переключение работающей версии приложений, регистрацию лицензии, сохранение загруженных файлов или автоматический аварийный откат штатного обновлятора. Для закрытия #425 необходим отдельный стенд полного обновления с проверкой этих этапов на Windows/OSPanel.
