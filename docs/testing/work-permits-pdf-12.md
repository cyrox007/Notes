# Notes 1.2 — локальная печать наряда-допуска в PDF

## Реализовано

По кнопке «Скачать PDF» выданный либо закрытый **наряд-допуск** формируется
на сервере без обращения к стороннему сервису или внешнему сайту.
Ссылка появляется в личном журнале автора и в управленческом журнале
для пользователя с правом `work_permits.manage`.

Документ включает все фактически сохранённые сведения: организацию,
подразделение, номер и объект, роли и состав бригады, задание,
отдельные меры безопасности, сроки и дополнительные указания,
регистрацию выдачи, первичный и ежедневные допуски, инструктажи,
перерывы, историю изменения бригады, продления, полное окончание
работ и закрытие. Сведения берутся из защищённой серверной карточки,
а не из переданных браузером параметров.

Автономный построитель на PHP создаёт A4 PDF с встроенным
локальным TrueType-шрифтом, таблицей Unicode и переносом длинных
строк/таблиц на дополнительные страницы. Расширения для открытия
браузера, установленный офисный пакет, внешняя конвертация и
сетевые PDF-сервисы не требуются.

**Это печатная учётная копия, а не утверждённый юридически значимый
электронный оригинал с подписями.** Сравнение размеров, полей и
подписных блоков с подлинными утверждёнными бланками ещё является
частью приёмки. PDF содержит предупреждение об этом на страницах.

Распоряжения и невыданные черновики не экспортируются через этот
маршрут под видом наряда; сервер возвращает конфликт 409.
Доступ к чужому наряду без `work_permits.manage` запрещён.
Ответ передаётся как `application/pdf`, с вложением для скачивания
и `Cache-Control: private, no-store`, без сохранения файла на сервере.

## Настройка шрифта

Для кириллицы требуется читаемый локальный шрифт TrueType с
картой Unicode (например, DejaVu Sans). На Ubuntu обычно подходит:

```bash
sudo apt-get install fonts-dejavu-core
```

На Windows/OSPanel используются доступные шрифты Windows,
например Arial или Tahoma.

Если шрифт установлен в другом каталоге, задайте окружение PHP:

```bash
WORK_PERMITS_PDF_FONT=/путь/к/шрифту/DejaVuSans.ttf
```

Это должен быть локальный файл TTF размером не более 5 МБ.
Шрифтовые файлы в репозиторий не копируются. Если совместимого
шрифта нет, маршрут возвращает код 503 с диагностикой, не отдавая
битый PDF.

## Проверки

```bash
php tests/integration/work_permits_pdf_mysql_12.php
```

Сценарий автоматически повторяет весь жизненный цикл наряда до
закрытия, проверяет наличие и структуру PDF, встроенный шрифт,
кириллический текст через `pdftotext`, число страниц через `pdfinfo`
и отрисовку первой страницы через `pdftoppm`. В тестах есть два
производственных образца из спецификации:

- ПС 35 кВ «Болдыревка» — несколько подготовительных отключений;
- ПС 110 кВ «Жилзона» — отсутствие отключений и большое количество
  ежедневных допусков с автоматическим переносом.

Для запуска тестов нужны `poppler-utils` и `fonts-dejavu-core`,
которые устанавливаются в профильном GitHub Actions.

## Ограничения и следующие шаги

Собственный PDF-движок имеет ограничение 180 страниц и не копирует
законодательный бланк пиксель в пиксель: необходима отдельная проверка
соответствия подписных и табличных областей действующей форме,
включая длинные документы и многостраничность.

До приёмки Notes 1.2 остаются шаблоны условий и отдельных указаний,
полные браузерные и мобильные сценарии, нагрузочная проверка массовой
печати, согласование границ рабочего дня с часовым поясом организации
и формальное сравнение печатной формы с оригиналами. Задача #421
остаётся открытой. Модуль выключен по умолчанию, релиз 1.2 не опубликован.
