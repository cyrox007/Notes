# Шаблоны заданий и составов бригад в Notes 1.2

Добавлены шаблоны, привязанные к организации. Вид «Задание» хранит текст работ; вид «Бригада» хранит назначения сотрудников по ролям и перечень членов бригады. Шаблоны не создают наряд автоматически: выбор копирует содержимое в форму черновика, где его можно изменить до сохранения.

Создание, переименование, замена содержания, архивирование и восстановление доступны только с правом `work_permits.manage`. Просмотр активных шаблонов доступен с `work_permits.use`; чтение архивных требует права управления. Изменения учитывают `version`, конфликт приводит к ответу 409. Архивный шаблон нельзя использовать для нового черновика. Сервер проверяет принадлежность каждого сотрудника организации и доступность его записи.

Схема включает `work_permit_templates`, `work_permit_template_crew`, `work_permit_template_history`. Отдельная миграция не меняет ранее существующие документы.

Проверка: `php tests/integration/work_permits_templates_mysql_12.php`. Тест покрывает оба вида шаблонов, совмещение ролей, сохранение содержимого, повторное редактирование, версии, архив и границы организации.
