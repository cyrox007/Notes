# Notes 1.2 — подписка на Push по категориям

## Что изменилось

Регистрация браузерного устройства уже была реализована в установленной PWA,
но в пользовательских настройках оставалась надпись «Browser Push · позже».
Пользователь не мог включить доставку конкретных категорий на телефон из панели.

Теперь в центре уведомлений, в разделе настроек каждой категории,
появился рабочий переключатель **«Push на устройствах»**.

- Сначала пользователь явно разрешает Push в блоке «Уведомления на этом устройстве».
- После регистрации настройки категорий обновляются с сервера, без перезагрузки страницы.
- Пользователь включает Push только для выбранных категорий. Внешняя доставка
  по-прежнему требует отдельного согласия.
- После отключения последнего устройства доступность пересчитывается; старая
  включённая подписка остаётся видимой и может быть выключена.
- Если регистрация завершается во время загрузки настроек, изменения не теряются:
  обновление повторяется после ответа предыдущего запроса.

На уровне сервера применяются существующие `DatabaseNotificationPreferences`,
`PushSubscriptionService` и очередь `NotificationDeliveryRuntime`.
Никаких новых разрешений или скрытой автоматической подписки не добавлено.

## Проверка

1. Откройте Notes через HTTPS в браузере с поддержкой Web Push.
2. Перейдите в «Центр уведомлений → Настройки».
3. До регистрации устройства переключатель Push для неподписанной категории
   недоступен с пояснением причины.
4. Нажмите «Включить Push», предоставьте разрешение и проверьте, что настройка
   соответствующей категории стала доступной без обновления страницы.
5. Включите внешнюю доставку и Push для нужной категории, закройте панель
   и снова откройте её: выбор должен сохраниться.
6. Нажмите «Отключить Push на этом устройстве». Если иных устройств нет,
   возможность включить новые категории должна исчезнуть, но выключить
   ранее выбранную категорию должно быть возможно.
7. Для фактической доставки выполните отдельную пробную отправку в админке,
   проверьте журнал попыток и получение на контролируемом устройстве.

## Автоматические проверки

```bash
node --check assets/js/notification-center.js
node --check assets/js/pwa-push.js
node tests/integration/notification_push_preferences_ui_12.mjs
node tests/integration/notification_pwa_push_12.mjs
php tests/integration/notification_preferences_contract.php
```

Автоматический сценарий проверяет отображение и доступность переключателя,
но не подменяет настоящий браузер, HTTPS, разрешение устройства и Web Push
на целевом сервере. Задача #424 остаётся открытой до полной приёмки.
