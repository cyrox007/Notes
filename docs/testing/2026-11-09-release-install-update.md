# Приёмка установки и обновления 1.2 — Windows, 9 ноября 2026

Кандидат: 1.2.0-rc.1 / 12000. Рабочая база `notes` не изменялась. Стенд: отдельные базы `notes_release_test_20261109_*`, PHP 8.3.30, MySQL 8.4, Chromium на Windows. Приёмка интерфейса описана отдельно в `2026-11-09-windows-combined-acceptance.md`.

## Исправления

- Начальная схема Defects получила разрешения и назначения ролей, которые ранее выдавались только миграцией. Опубликованные миграции не изменены.
- Изолированный обновлятор знал SQL-идентификаторы старого пакета: его фильтр метаданных скрывал новые таблицы. Мигратор теперь расширяет пространство имён таблицами и SQL-объектами проверенного целевого пакета. Проверка готовности также учитывает целевой состав.
- После отката оставались пустые каталоги новых модулей без манифестов. Добавлена очистка пустых release-owned каталогов; пользовательские и приватные каталоги защищены. Регрессионный тест проверяет оба условия.
- Подготовительный инструмент 1.1 принимает доверенный RC 1.2 и включён в runtime ZIP.

## Границы проверки

Браузерное обновление выполнено без process API, отдельными PHP HTTP-запросами через внешний вход продолжения. До него на копию точного тега v1.1.0 установлен подготовительный инструмент. Произвольный неподготовленный старый updater этим не проверен.

Испытательный ZIP отличается от кандидата только двумя реестрами публичных ключей: `config/license_trusted_keys.php` и `config/update_trusted_keys.php`. Это необходимо для локальной испытательной лицензии и отдельной тестовой подписи. Неизменённый ZIP и подписанная испытательная сборка хранятся раздельно. Production-подпись этим не подтверждена; секретов испытаний в кандидате нет.

Первый прогон обнаружил отказ миграционной проверки и пустые каталоги отката — обе ошибки исправлены. Отдельная попытка нажала кнопку до готовности клиентского обработчика и попала в синхронный fallback; успешный повтор использовал штатные HTTP-продолжения. Два первоначальных запуска browser installer имели неверный document root стенда; после исправления обе чистые установки пройдены. Эти попытки не включены в число успешных.

Локальные доказательства: `C:/OSPanel/audit/release-tests-20261109/`: `matrix-results.json`, `frozen-matrix-results.json`, `installer-web-results.json`, `browser-update-result.json`, `installed-inventory.json`, `real-recovery-0.log`, `real-recovery-prefix-0.log`. В соседних файлах есть приватные материалы; каталог нельзя публиковать целиком.

## Допуск к выпуску

Подготовлен RC, не stable/latest. E2EE из чернового PR #552 не входит в кандидат; физическая приёмка и независимый криптоаудит не завершены. Реальная внешняя доставка, звонки и нагрузочная приёмка не подтверждены настроенными каналами и устройствами. Production-подпись, окончательные CI и stable-публикация остаются отдельными этапами. Установка и обновление не заменяют эти критерии.
