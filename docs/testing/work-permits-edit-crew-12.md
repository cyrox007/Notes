# Notes 1.2 — редактирование черновика и состав бригады

## Функциональность

В личном журнале у черновика появилась кнопка «Открыть и изменить».
Пользователь может изменить организацию, подразделение, объект и задание.
Можно назначить работников из справочника на следующие роли:

- выдавший документ;
- ответственный руководитель;
- допускающий (по умолчанию — «оперативный персонал»);
- производитель работ;
- наблюдающий (по умолчанию — «не назначается»);
- несколько членов бригады.

Один сотрудник может одновременно занимать несколько ролей. Записи сотрудников
сохраняются отдельно, вместе со снимком ФИО и группы электробезопасности:
переименование справочника не изменяет прежние сведения в карточке.

## Безопасность и повторное сохранение

Редактировать можно **только собственный черновик**. Состояния `issued` и
`closed` блокируют этот маршрут. Каждый запрос передаёт ожидаемую
`version` и уникальный `command_id`.

В одной транзакции обновляются данные карточки, заменяются записи состава
бригады, добавляется история и фиксируется обработанная команда.
Перед сравнением версии строка документа блокируется для записи.
Устаревшая версия вызывает 409, чужая карточка — 404.

Повтор той же команды возвращает прежний результат, включая случай
последующего переименования или архивирования сотрудника. Повтор команды
с изменёнными данными запрещён. Новая команда не может назначить
архивированного работника или работника другой организации.
