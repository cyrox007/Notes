# Проверка предварительного этапа обновления Notes 1.1.0 → 1.2.0

Штатный UpdateDatabaseMigrator теперь проверяет существование журнала schema_migrations по фактическому имени таблицы через PrefixMysqli и DatabasePrefix. Системная таблица может находиться как без префикса, так и с DBPREFIX.

## Автоматические испытания

Выполнить: php tests/integration/upgrade_11000_to_12000_preflight_mysql.php

Тест на MySQL 8.4 проверяет оба варианта DBPREFIX: пустой и nt12_. Для каждой схемы подготавливается журнал опубликованной версии 1.1.0 с историческими контрольными суммами. Сверяются штатные read-only preflight и статус мигратора, порядок и количество ожидающих миграций. Подмена контрольной суммы должна быть отвергнута. После удаления журнала проверяется переход по историческому baseline 1.1.0. Тест не выполняет новые миграции и не меняет пользовательские таблицы.

## Ограничения готовности релиза

Эта проверка закрывает отдельный риск распознавания журнала с DBPREFIX, но не заменяет полный запуск обновлятора из неизменяемого тега v1.1.0 с резервной копией, кодовым переключением, применением всех миграций, проверкой восстановления и Windows/OSPanel. Полная приёмка #425 и выпуск 1.2.0 остаются заблокированными до сквозного испытания на точном SHA кандидата релиза.
