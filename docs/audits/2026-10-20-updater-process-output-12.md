# Notes 1.2 — ограничение памяти вывода обновлятора

Дата: 20 октября 2026 года.

## Причина исправления

`Core\UpdateProcessRunner` ранее без ограничения накапливал `stdout` и `stderr` запущенной команды обновления. Длительный запуск, особенно при диагностическом выводе, мог увеличивать потребление памяти PHP пропорционально количеству сообщений.

## Реализация

- Из каждого канала сохраняется **не больше 1 МиБ первых байтов**. Формат результата `code`, `stdout`, `stderr` и порядок сообщений внутри каждого канала остаются прежними.
- Чтение идёт порциями по **64 КиБ** и продолжается после заполнения сохранённого буфера. Таким образом, дочерний процесс не блокируется из-за заполнения канала, а временные строки чтения также остаются ограниченными.
- После завершения дочерней команды оставшиеся данные обоих каналов вычитываются до пустого чтения, даже если лимит сохранения давно достигнут. Возвращается настоящий код завершения процесса; существующее поведение тайм-аута оставлено без изменений.
- Между запусками нет кэша и дополнительного файлового журнала. Полный неограниченный вывод намеренно **не сохраняется**; для диагностики инцидентов используются ограниченные сообщения, состояние обновления и отдельные системные журналы.

## Проверки

`tests/integration/php83_runtime_contract.php` запускается на PHP 8.3 в Linux и Windows и проверяет обычную команду, код завершения, по 2 МиБ вывода с каждого канала, повторяющиеся большие блоки (по 6 МиБ в `stdout` и `stderr`), ограничение сохранения до 1 МиБ на канал, рост памяти родительского PHP и пустые каналы.

Приёмка требует **успешного завершения обоих профильных заданий PHP 8.3**, остальных обязательных проверок CI и отсутствия конфликтов с актуальной веткой `1.2`. Отменённый Windows-запуск нельзя приравнивать к успешному.

## Границы

Ограничена память, используемая **для хранения вывода процессов обновлятора**, а не общая память самого обновления или произвольно запускаемого дочернего процесса. Испытания не заменяют полный сценарий отказоустойчивого обновления на целевых системах.
